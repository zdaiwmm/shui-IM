# 聊天界面问题修复记录

本次对应用户提供的两张截图和十项反馈，已修改本地项目，未发布线上。

| 项目 | 修改及验证 |
| --- | --- |
| 键盘上方留白 | 视口变化按帧合并，平移不再修改文档底部占位；软键盘展开时去掉输入区重复的底部安全区。模拟视口下输入框到可视区底部为 9px。iPhone Safari 系统键盘仍需真机复核。 |
| 系统工具栏 | Safari 的地址标识、上一项/下一项与完成属于浏览器和系统界面，网页无法可靠强制隐藏。输入区关闭表单自动填充，但不能保证系统工具栏消失。 |
| 相册底部间距 | 修复网格行高被压缩、照片溢出挤占底部间距的问题，保留正方形行高。最后一行到提示文字实测 39px。 |
| 在线状态 | 中间状态胶囊第一行按“我＋状态点、对方＋状态点”排列，第二行展示对方在线或最近在线时间。 |
| 表情回应闪动 | 菜单遮罩和选中消息同步淡出，表情确认时保留徽标元素。 |
| 上滑抖动 | 上滑意图立即取消跟随，键盘收起前的触摸也先暂停跟随；到达底部的下滑和主动发送恢复跟随。单条长消息同样保留阅读位置。 |
| 未读数为 0 | 注册观察凭据不再把已同步消息当成已读；注册前保存只读计数凭据；打开会话尽早注册，并在前台持续刷新。 |
| 表情蓝圈 | 长按后焦点落在菜单容器，避免默认给第一个表情加焦点圈。键盘导航仍有可见焦点。 |
| 引用消息 | 移除引用背景和圆角卡片，只保留前面的竖线及文字。 |
| 毛玻璃边缘 | 去除多重内阴影和外圈，使用单边框、柔和投影和垂直高光。 |

## 验证

- 聊天生命周期浏览器回归通过，包含新增轻微上滑、视口平移、键盘收起时序、单条长消息、表情元素稳定性、相册行高和间距检查。
- 双端浏览器流程通过，覆盖状态、回复、表情、消息收发、语音与隐私清理。
- 未读浏览器回归通过：收到消息为 1，可见后为 0，锁定后再收消息并重载恢复为 1；锁定读取仅使用计数凭据。
- 未读计数、未读服务端和表情投影的 27 项测试通过。
- TypeScript 检查通过，构建通过。依赖构建警告不影响输出。
- 已检查浅色、深色、320px 小屏与相册底部截图。图中照片为测试占位内容。

## 限制

桌面 Chromium 的模拟视口无法复现完整的 iOS Safari 浏览器工具栏和系统键盘动画。第 1、6 项的真机效果应在更新后按原操作路径复核。本次没有线上发布。
