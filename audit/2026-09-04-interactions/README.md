# 移动端交互修整验收

范围：本次用户提出的 24 项界面、动效、媒体、录音与原生选择器反馈。生产版本和回读以 `RELEASING.md`、`docs/context/status.md` 为准；本记录不把桌面模拟结果写成真实 iPhone 验收。

## 需求与处理

| 需求编号 | 实现与边界 | 主要自动回归 |
| --- | --- | --- |
| 1、5 | 聊天可见时持续采样视口；固定控件直接使用同次几何，离开/锁定取消，查看器返回后恢复。原生合成器未公开的几何无法由网页预知。 | `frontend-lifecycle.e2e.mjs` |

## 额外发现并修复

- 排队的旧滚动帧不再关闭刚打开的消息菜单；后续真实滚动仍关闭菜单。
- 普通与安全错误清理均销毁图片手势绑定，不保留旧查看器闭包。
- 延迟全屏请求成功时，若原查看器已结束，立即退出该旧视频的全屏。
- 图片缩放与平移不受旧 CSS transform 过渡拖慢。
- 页面退出中的锁定会取消延迟导航，不能恢复已遮罩的私密内容。
