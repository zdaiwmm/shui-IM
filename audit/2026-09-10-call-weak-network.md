## 实际实现

详细阶段时钟、错误码、恢复动作和阈值见 [CALLS.md](../CALLS.md#弱网连接策略与诊断2026-09-10)。

- 十个阶段分别计时、诊断和清理；幂等进入不延长截止时间，异步迟到结果受通话生命周期隔离。ICE 成功、DTLS 建立和音频轨道可用分别确认。
- 初始允许 host、STUN、TURN UDP/TCP/TLS 参与浏览器 ICE；多 URL、地域标记及候选预收集保留。失败依次重新收集并 restart、刷新配置、relay-only，达到预算明确结束。正常路径不因一次高 RTT 或 online 事件重启。
- 配置请求每次包含响应体在内限时 4 秒，按 250/500/1000ms 有限退避。严格校验 URL、transport、地址、有效期和 relay-only；TURN 提前刷新失败保留已连接媒体，过期配置不能用于新的 ICE restart。
- 信令发送使用服务器 ACK，同 callId/eventId 的原签名密文可重传。服务端已处理事件只重发 ACK；暂时不可达或背压的事件继续保留。重绑定恢复原设备选择；锁定、pagehide、freeze、成员权限失效优先清理。
- RTT、jitter、双向丢包、可用带宽、选中候选对和音轨状态共同驱动 good/degraded/audio-only/recovering。连续坏样本逐级降低码率、分辨率、帧率后暂停视频，连续好样本逐级恢复；用户停用摄像头会取消自动恢复。
- 已建立音频短暂 mute 保留本地音频和成功路径，等待恢复总预算；首次音频缺失仍用独立 10 秒截止。保留轨道不代表断网期间能够听见远端声音。
- 语音上传连接、中途失败、确认不明、下载、解密和解码错误分开处理。复用原消息 ID、blobId、上传 plan 和密文；完成确认丢失先查同 blob 状态，已有待发箱或历史记录避免重复消息和重复推进 MLS。
- 解锁时 `window.quietRoomCallDiagnostics?.()` 可读取当前通话最多 64 条内存事件；callId 带随机盐哈希。记录阶段、耗时、错误、候选类型/协议和质量数值；不记录访问令牌、TURN 密钥、完整 SDP/候选、真实设备标识、消息和媒体内容，不持久化或上传。

## 故障场景覆盖

| 请求场景 | 自动故障方式与验证 |
| --- | --- |
| 延迟 100/300/800ms | 合成信令延迟及 CDP 原生 WebRTC 网络整形分别运行；记录首次接通时间 |
| 丢包 5/10/20% | 信令/ACK 丢失与 CDP RTP 丢包分别运行；原生媒体采样记录实际观测丢包，不将配置百分比当成实测值 |
| 上下行不对称 | CDP 上行或下行 40,000 bytes/s、另一向 500,000 bytes/s；另以可重复统计输入验证质量降级/恢复 |
| DNS/配置响应延迟 | 配置响应延迟和整个请求/响应体超时夹具；不代表真实 DNS 解析器故障 |
| WebSocket 断开 1/5/15 秒 | 控制器时钟与浏览器信令通道中断；真实服务端 WebSocket 测试另验证同设备重绑定、确认和拒绝 |
| TURN UDP 失败、TCP 可用 | 控制器注入节点错误和选中 relay/tcp 候选；非真实 TURN 防火墙测试 |
| TURN TCP 失败、TLS 可用 | 控制器注入选中 relay/tls 候选；非真实 TURN TLS 联网验收 |
| 首次 ICE 失败、第二次 relay 成功 | 控制器重收集后 relay 候选成功；另验证所有阶梯失败时的明确结束码 |
| 接通后网络切换 | 控制器断开/恢复和 Chrome 原生 ICE restart；未验证实际蜂窝/Wi-Fi 路由切换 |
| 建立中 pagehide/freeze/锁定 | 应用与控制器生命周期专项，验证晚到权限结果轨道被停止和下一次通话可发起 |
| 残留旧 callId 后新通话 | 控制器与服务端仲裁验证替换、迟到信令隔离和旧队列取消 |
| 视频降为音频后恢复 | 原生媒体配合受控统计输入及控制器虚拟时钟；验证逐级恢复、音频保持和手动停用优先 |
