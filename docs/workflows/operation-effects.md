# 操作影响对照

适用于 2026-10-25 的新密室与本人独立归档；存量 QR3／QR4 和个人根流程继续按各自契约处理。
本页核对已有行为，不新增权限、远程抹除承诺或正式页面交互。

## 删除、移除与退出

| 操作 | 作用范围与后果 | 保留内容／恢复条件 | 权威来源 |
| --- | --- | --- | --- |
| 从密室列表移除 | 移除本人目录入口，同步到有共同授权连接的本人设备；离线设备稍后同步 | 本机原有内容、对方状态、设备成员资格与独立归档保留；目录发现或恢复列表不自动授予加入资格 | [新密室目录](../../NEW_ROOM_ARCHIVES.md#2026-10-25-本人设备目录同步)、[目录实现](../../src/lib/own-space-directory.ts) |
| 撤销／接替指定设备 | 服务端停用指定旧端的未来成员能力；接替必须绑定具体旧设备并完成授权 | 不能远程擦除旧端已读内容、导出文件或复制的密文；其他设备按各自身份继续，新增端受历史下界约束 | [安全模型](../../SECURITY.md)、[设备及协议入口](../../server/storage.mjs) |
| 清除此浏览器数据 | 经确认与保护版本校验，删除本浏览器全部密室、本机历史和保护材料 | 不删除对方、独立云端归档或已导出文件；本机未上传且无副本的内容可能无法找回；恢复卡不重置原应用锁 | [应用锁契约](../../NEW_ROOM_ARCHIVES.md)、[本机事务](../../src/lib/vault.ts) |
| 聊天删除 | 按现有权限写入已认证删除投影，隐藏目标聊天记录及其聊天收藏投影 | 不等于附件物理销毁或擦除离线端、备份、导出；保险箱独立副本按自身整理规则保留 | [安全模型](../../SECURITY.md)、[删除投影](../../src/lib/message-deletions.ts) |
| 保险箱整理 | 改变本人保险箱的加密本机整理投影 | 不撤销聊天消息或对方副本；独立副本和备份边界按契约处理 | [产品契约](../../PRODUCT.md)、[整理投影](../../src/lib/gallery-curation.ts) |
| 管理员删除来源密室 | 经过后台认证和危险操作验证，清理该来源的在线房间与关联资源 | 新版本人独立归档不级联删除，仍可按原归档能力读取；独立快照与设备副本保留 | [运维](../../OPERATIONS.md)、[独立归档契约](../../NEW_ROOM_ARCHIVES.md#2026-10-25-管理元数据) |

## 保护与恢复

| 能力／操作 | 能做什么 | 不能替代什么 |
| --- | --- | --- |
| 本机应用锁 | 保护本浏览器解密材料；开启后按已有生命周期锁定 | 不授予房间成员资格、不重置归档口令、不删除远端副本；无锁时本浏览器可自动解密 |
| 恢复凭证原图＋独立口令 | 在本机解开本人归档材料，验证完整历史与原件后私有导入 | 不授予实时聊天成员资格，不绕过应用锁；截图、压缩图或其他归档的卡不能保证恢复 |
| 修改凭证口令 | 原口令及应用锁验证后轮换在线读取能力，完成保存后停用此前导出图的在线取件 | 不撤销已下载密文或已解密内容；需导出并回验新图；单纯重新导出不撤销旧图 |
| 关闭自动备份 | 暂停当前浏览器当前密室的自动任务，保留待传对象；重开复用原 ID | 不删除云端已有密文、不改变其他设备；显式立即备份仍可执行 |
| 本人聊天归档 | 前台、解锁、联网时备份聊天及原附件；以实际提交／回读进度为准 | 不包含设备身份私钥、MLS 状态或应用锁口令；未完成上传不算已备份 |
| Mac 服务器灾备 | 保存服务器数据库和密文附件的独立恢复副本，按回执判断新鲜度 | 不证明各浏览器已上传最新聊天，不提供不可变存储或 Mac 离线时的连续备份 |

详细恢复范围、口令轮换与错误边界以 [NEW_ROOM_ARCHIVES.md](../../NEW_ROOM_ARCHIVES.md)、
[SECURITY.md](../../SECURITY.md) 和 [OPERATIONS.md](../../OPERATIONS.md) 为准。

## 页面核对方式

按入口、动作名、确认后果、取消／失败、成功反馈逐项核对上述范围；不要仅凭按钮名称推断后果。
发现正式页面需要改动时，先在本需求内交付沿用实际设计体系的原型和业务流程图，再确认实施。
本对照表不将桌面自动化写成真机验证，也不授权生产发布。
