# 后台组件与页面

2026-10-25 V1：后台由总览、密室管理、归档与备份、表情资源、运维诊断、安全与审计六个入口组成。设计与授权见[需求记录](../requirements/2026-10-25-admin-v1/README.md)。

后台使用现有原生 TypeScript/DOM 与本地 Lucide，组件入口为 `src/admin/ui.ts`，
设计令牌与响应式布局为 `src/admin.css`，页面编排为 `src/admin.ts`，新管理页面为 `src/admin/workspace.ts`，只读投影与诊断分别为 `server/admin-data.mjs` 和 `server/admin-diagnostics.mjs`。
这是项目本地组件层，不宣称安装了第三方后台框架；不加载 CDN、远程字体或分析脚本。

## 组件契约

- `pageToolbar`：页面分组标题、真实计数和图标操作；不放无数据支持的健康/统计结论。
- `table` / `row`：统一表头、单元格和窄屏字段标签，数据写入使用 `textContent`。
- `pagination`：会话列表使用服务端既有 50 项 offset；资源库使用 24 项页码、总量、首尾页和跳转。
- `badge`：成功、警告、错误、中性四种语义，必须同时显示文本，不能只靠颜色传达状态。
- `iconButton`：本地 Lucide、可访问名称、悬停标题、固定 44px 操作区域。
- `loadingState` / `emptyState` / `errorState`：有界占位、空结果和显式读取重试。
- 页面通知区区分成功与失败，可手动关闭，不自动重放失败写入。

CSS 根变量定义表面、边框、文本、强调色、语义色、圆角和过渡时间。
样式仅由后台入口加载。系统明暗主题自动适配；小屏侧栏转顶部导航，表格按字段排列，
分页与批量操作换行；减少动态效果时关闭过渡。资源详情编辑区和预览区按可用宽度分栏。

## 页面边界

会话列表、设备备份详情、清理表单，及 GIF/贴图列表、状态筛选、上传、批量上下架、
资源编辑预览与删除共用上述组件。表情采集单独使用后台导航入口，按渠道展示已验证的来源；
提供 Signal Stickers 贴图合集与 Google Noto 动画渠道，可切换来源、分页搜索并进入对应资源管理。
按稳定来源 ID 采集，完整校验后自动上架；已入库资源禁用重复采集。搜索按钮保持横排，卡片操作独立一行。
未通过真实采集验证的来源不显示在后台。上传仍直接打开本机选择器，以文件名命名并默认上架；
选择状态在页面刷新、分类和筛选切换后清空。
后台不提供聊天明文、恢复码或密钥查看。密码/TOTP、Cookie、CSRF、清理二次验证沿用
[恢复与后台契约](../../RECOVERY_BACKUPS.md#会话管理后台)。

## 验证

`tests/backup-admin-ui.e2e.mjs` 覆盖真实后台登录、读取失败重试、刷新、分类键盘操作、
上架状态筛选、上传编辑、批量上下架、分页、删除、会话续期与退出。
可传入截图目录保存合成数据截图；桌面和 320/390/768px 检查不等于 iPhone 真机验证。
认证与来源边界继续由 `tests/admin.test.ts` 验证。跨页面改动执行 `npm run check:full`。

2026-09-11：页面首次读取不受后台轮询的聚焦条件限制；后台 GET 读取最多等待 20 秒，采集任务读取为 15 秒，超时显示重试。切页取消旧页面读取与预览，重新搜索取消旧搜索；原图预览前端最多三路并发，单张等待上限 20 秒，避免慢图占满同源连接。写操作超时只提示刷新确认，不自动重放。管理员首次登录后 7 天到期，退出立即撤销，服务重启仍需重新登录。

## V1 管理数据边界

密室通过编号和格式/状态筛选；已授权设备与实际在线分开。后台不读取本机密室名称、自动备份开关、媒体分类或用户私有收藏。新版归档独立于实时密室，新版对象数不是消息数、完整性或可恢复性证明。旧版恢复包、版本、更新时间和聊天/保险箱统计保留在明确标注的旧版区域。

归档列表可检索来源已移除的归档，只显示编号、角色、写入端授权、对象数、字节数及可核实时间。新注册与实际新增对象有事务内时间记录；原数据未记录的时间为未知，幂等重试不刷新。无归档删除、读取能力、口令或代恢复入口。

危险操作独立分栏。完整编号、密码和新 TOTP 验证之前列明影响范围；删除实时密室及关联旧版数据，但保留新版独立归档、独立灾备和设备副本。超时先查询，不自动重放。

表情管理/采集/任务/应用内置说明共用资源分栏。首页优先贴纸；GIF 兼容保留；64 个 Fluent 动画随应用版本维护，后台只读。成功表情写操作记录最小动作/目标/结果元数据；既有密室删除审计只表示已登记，附件最终清理结果由持久队列另查。失败请求不被写成成功。

## 诊断来源

应用检查只证明当前数据库事务与目录访问。通知启用、通话配置格式、TURN 已配置与实际送达/连通性分开。构建版本从当前 `sw.js` 首部读取，不假装获得部署 SHA、容器健康或生产独立回读。额度不是主机剩余磁盘。

Compose 提供独立 `quiet-room-admin-status` 卷：备份进程写入，应用只读。`scripts/backup-admin-status.mjs` 每 30 秒从既有状态生成最多 4 KiB 的白名单摘要（含采样时间），不共享快照目录。应用的 `ADMIN_BACKUP_STATUS_FILE` 指向卷中的 `backup.json`；超过 120 秒、未来或无效采样显示未知，回执仍沿用 备份进程实际模式与有效期门禁（缺省 36 小时）。摘要发布失败不改变备份结果，失联后旧摘要自行失效。未配置、文件无效或不可读显示未接入/无效，不遍历快照、不返回路径及原始字段。Compose 配置存在不证明生产已部署或回执已验证，也不替代恢复演练。

`tests/admin-data.test.ts` 覆盖元数据白名单、来源删除后独立读取、旧日期未知和重试时间、筛选与诊断边界；`tests/admin-workspace.e2e.mjs` 使用真实本地认证与合成数据，覆盖六入口、格式筛选、危险操作、独立归档保留、错误重试及渲染。该专项已纳入完整浏览器入口，原采集与备份后台浏览器测试继续保留。
