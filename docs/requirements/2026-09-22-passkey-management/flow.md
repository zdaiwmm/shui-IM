# D2 业务流程（对应静态图）

## 当前密钥管理

点击设置入口 07 → 立即唤起系统指定凭据验证，底页保持设置 08 → 成功后才进入 09／旧记录进入 13。没有单独验证页面，也没有第二次“发起验证”点击。

- 进入验证取消、失败：设置内状态 14，点击原入口重试；不得显示名称。
- 环境／提供方不支持更新，或旧 userHandle 无法可靠取得：提前限制编辑，15。
- 点击修改／设置名称：在管理页上打开输入弹窗 10，同一点击内聚焦输入框并选中名称，唤起键盘；空白或长度非法：弹窗内 21，不调用系统验证。
- 点击弹窗“验证并保存”：保留弹窗底页 11，直接再次验证指定当前凭据。
- 验证取消：回到 10，保留草稿，名称不变。
- 更新前明确失败：16，可重试或取消。
- 系统已接收更新、应用记录保存成功：关闭弹窗，返回管理页 12。
- 系统已接收更新、应用记录未保存：弹窗内 20，不声称回滚。重新认证后以同一名称重试。
- 任意阶段锁定、隐藏或退出触发项目既有隐私生命周期；未完成操作作废，迟到结果不得打开页面或提交下一次修改。

## 新空间与密钥

欢迎 01：首位蓝色“创建私密空间” → 命名 02 → 系统创建通行密钥 → 自动创建空间 → 邀请弹窗 03。没有单独加入页，也不进入新浏览器的受限空间授权页。

欢迎第二项“接入本设备现存私密空间” → 选择已有凭据 → 接入请求 05。

旧保险库首次绑定 19、恢复后的重新绑定 04，复用名称组件，其前置验证与安全确认保持原流程。他人邀请加入属于独立既有业务，不混入创建流程。

已解锁空间内继续创建 → 复用当前凭据 → 既有邀请面板；不进入 02，不多创建一把密钥。

## 新浏览器与旧端

01 → 系统选择已有密钥 → 新浏览器请求 05 → 旧端在线并解锁 → 旧端核对码批准 17 → 加密目录交付 → 受限空间外壳 18 → 申请对方授权 → 既有空间批准与安全加入 → 开放聊天。

- 新浏览器取消验证：停留入口，不发请求。
- 等待期间重选：撤销／隔离原请求，再次选择凭据并新建请求；旧请求迟到批准不能被消费。
- 超时：06，明确不代表原空间不存在。
- 旧端拒绝：结束本次请求，可重新发起；不授予目录或聊天权限。
- 图 18 不代表加入完成，不能显示消息、预览、在线状态或输入框。

用户本轮要求静态图，以上文字流程供逐页核对；没有模拟安全协议或操作真实密钥。
