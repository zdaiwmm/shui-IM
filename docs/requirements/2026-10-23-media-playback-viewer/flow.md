# 媒体播放与控件修订流程 V1

原型图示由同目录 `prototype/flow.html` 提供。模拟界面不证明原件认证、真实视频解码或 Safari 系统行为通过。

```mermaid
flowchart TD
  A[聊天或创建者保险箱相册] --> B[首次点击显露已验证缩略图]
  B --> C[再次点击打开指定媒体]
  C --> D{图片或视频}
  D -->|图片| E[图片查看器：关闭、翻页；按来源提供收藏或详情与删除]
  D -->|视频| F[完整原件校验，或读取绑定原清单的已验证播放缓存]
  F --> G{已有缩略图缓存}
  G -->|是| H[升级为视频来源，保留封面，核对 URL 及计数]
  G -->|否| I[建立视频缓存]
  H --> J{聊天直接打开且原生播放可用}
  I --> J
  J -->|是| K[请求原生播放器；成功后由系统提供控件]
  J -->|否或拒绝| L[页内视频：中央播放；底部独立进度与工具]
  K -->|请求被拒绝| L
  L --> M{实际播放结果}
  M -->|允许| N[播放、暂停、进度、声音与可见倍速]
  M -->|手势权限不足| O[独立提示点按播放]
  O --> L
  M -->|不可解码| P[独立错误说明；保留关闭或翻页]
  F -->|加载失败| Q[独立加载失败状态与重试]
  Q --> F
  E --> R[关闭或翻页]
  N --> R
  P --> R
  R --> S[立即停止旧视频并移除来源；返回或切换项目]
  T[失焦、锁定或隐私清理] --> U[立即取消工作、清除显示并释放媒体资源]
```

Safe 删除仅影响本设备保险箱投影，需显式确认；取消无变化，持久化失败保留重试。聊天和收藏不新增保险箱删除／下载权限。翻页到视频继续沿用实际当前的页内暂停路径，不在本次样式修订中改变为原生自动播放。PRODUCT.md 旧句与当前代码／SECURITY.md 的该项漂移已记录，正式实施时保持现行行为并做必要事实对账。
