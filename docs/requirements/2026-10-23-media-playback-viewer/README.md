## 已确认的目标与方案

1. 修复聊天和相册重新进入后的视频播放：已有 JPEG 预览时，`loadImage()` 读取播放副本后被 `cacheLocalImage()` 的已存在条目提前返回挡住，错误地将预览 URL 作为视频来源。升级时保留封面用途，更新视频 Blob、URL、状态及内存计数；不改变原件校验、原始字节、密钥、恢复或持久缓存契约。
2. 页内视频中央播放／前后跳转按舞台定位，与底部进度／声音／倍速工具条分开。聊天移除重复的底部播放按钮；保险箱保留既有中央播放和删除入口。
3. 播放被浏览器拒绝、格式不可解码和加载失败使用独立状态区，播放按钮不覆盖文字。加载失败保留重试，格式错误保留关闭及翻页，不新增查看器下载。
4. 图片删除／翻页等浮动控件采用规范现有的深色媒体表面和高对比图形；文件名和时间使用局部不透明底，保留图片连续画布，不增加整条渐变遮罩。倍速显示实际数值。
5. 保留 Safe 独立删除、聊天收藏、详情权限、翻页暂停和原生播放器优先路径。关闭、失焦、锁定或隐私清理仍立即停止／清除媒体；视觉退出不延后清理。

排除：生产发布、编码兼容扩展、全站重设计、数据清理或迁移。原生 Safari 播放器外观不由页面控制。
