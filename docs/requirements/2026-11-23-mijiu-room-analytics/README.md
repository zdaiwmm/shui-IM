## 设计与口径

入口为管理后台的「密室运营」，沿用 [后台工作区设计](../../requirements/2026-10-25-admin-v1/README.md) 和 [管理页样式](../../../src/admin.css) 的导航、明暗表面与强调色。

- 存量按等待加入、双方已加入、关闭拆分。日期选择影响期间发生量、创建批次、留存和趋势，当前存量与有效订阅等快照使用固定截点。
- 受邀方完成首次加入时每室计一席。24 小时加入率及 7 天转化使用已满相应观察期的新建密室。聊天状态区分等待、已加入零消息、仅创建方、仅受邀方、双方均发送和历史未知。
- 消息活跃以服务端接受的普通聊天消息为准，同一发送的重试和控制事件不另计。首次成功发送后计算 D1、D7、D30，分母限定为已满对应观察期的密室。
- 功能表展示附件、多设备、推送、备份与恢复、音视频通话和本机隐私功能。当前记录可用于存量和覆盖范围内的回算。已清理的历史可能无法判定，通话接通等指标需要新增统计，客户端隐私事件需要单独确认。
- 汇总由业务侧完成，经管理后台呈现。Lead 保持访客流量用途。生产数据访问、数据留存变化及新增信号的语义和权限留待实施设计确认。

## 实现边界

- 页面和只读接口随现有后台登录启用。受保护的管理员环境配置需显式设置 `ADMIN_ROOM_ANALYTICS=1`。默认环境不展示入口。统计范围为该后台对应业务库。
- 日期采用北京时间，期间查询截至最近一个完整自然日。存量是查询时的快照。期间新建和加入只能回算仍在业务库中的密室。
- 首次成功发送及发言方来自现有可计数消息元数据。旧版未提供可计数标记时沿用服务端既有默认值。滚动清理造成缺口时，已见消息可作为正证据。无法确定的分类标为历史未知。留存仅纳入首次发送和对应回访可核实的密室。
- 关闭趋势只计仍关闭且可从服务器记录确定关闭时间的密室。实际通话接通、客户端本机操作与缺少结果记录的功能显示待采集或待确认。
- 只读汇总复用现有数据库元数据。此版没有新增采集接口、行为存储或消息保留期。只读工作线程使用同一 SQLite 快照完成查询。后台返回聚合计数和日期范围。

回归评级为高。新增受保护的管理员元数据读取路径并涉及隔离配置。验证包含完整应用检查与后台登录、环境隔离和浏览器交互专项。

本地定向验证已通过构建、指标和后台安全共 31 项测试，以及 Chromium 和本地 HTTPS WebKit 的后台工作区验收。本地阶段未验证物理 iPhone 和生产环境。
