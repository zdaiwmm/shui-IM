## 现状与提案
- 基线 src/app.ts 的 open-favorites 对双方开放，收藏共用 gallery-shell 的「相册／文件」标签。聊天顶部 open-gallery 及 safe 模式有创建者权限门。PRODUCT.md 的 Chat Images / Chat Files 规定附件单件 256 MiB 上限。现有 gallery-file 有加密传输，不适合作为仅本机条目。
- 双方聊天「＋」工具栏增加「链接视频」。本次评审模拟 X 公开帖子的两段视频。下载方式为设备直连 X；正式实现须单独核验 CSP 域名白名单、CORS、可取消的流式写入和本机可用空间，通道不代理视频。
- 仅下载写入自己的当前设备与房间的加密存储。缩略图默认遮蔽，角落锁图标附无障碍名称，详情可读「仅自己可见 · 本设备」。我的下载对双方开放；创建者保险箱相册聚合本机条目。私有数据隔离于聊天消息、待发、已读、通知、跨设备同步和备份。
- 下载并发送先落盘，在设备上无损整理并校验，未变小用原件，仍超 256 MiB 保留本地。上传和消息仅走原有加密发送通道。成功时创建一条消息并更新发送者此条目状态；重试复用本地素材。失败不会把本地条目标为已共享。
- 当前设计取舍：我的下载保留成功共享过的导入记录但撤下私有锁；仅下载遇到已保存的视频复用已有条目。取消前已完成落盘的数据保留。未设计其他平台、云端代下或有损降码率。

## 正式实施确认 · 2026-11-04
用户已确认 V1 原型和流程图并授权集成。追加的「我的下载」操作为长按封面弹出就地菜单，点击「发送至聊天」后才走同一条无损处理、大小校验及加密附件发送路径。更多操作按钮支持键盘与辅助操作。上述「待确认」和验收证据只描述早先的设计阶段。

公开帖子通过 FxTwitter 在设备端识别，仅发送帖子编号。设备直接从 X 媒体域读取 MP4，并在本机生成持久化封面。下载上限 1 GiB，实际受本机空间限制。进入聊天发送队列后仍保留私有标识，等待已校验的本人消息写入历史再移除。正式回归覆盖私有落盘、发送前后网络分界、两角色、加密队列及隐私中止。持久化与安全策略调整按完整回归验收。
