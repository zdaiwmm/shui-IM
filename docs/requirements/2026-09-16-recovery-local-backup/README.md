## 范围

创建主线、邀请状态与庆祝、可选遮蔽演练、入口卡片和盾牌；双方分别输入恢复码，支持只恢复我/对方/两人及范围变更重新确认；本人本地聊天备份的压缩、加密、原字节附件封装与导入。沿用 DESIGN.md tokens 和组件；页面画布保持不透明，玻璃材质只用于有边界的按钮、状态卡与弹层。

现有 QR3 自动服务端备份作为隐藏兼容入口保留（`#legacy-recovery`、`#legacy-backup`），不得在新显性流程中宣传为二取二保护。

## 旧设备取舍

双方签名确认同一恢复范围后，服务端原子撤销全部旧活跃/待加入设备。协助方保留本机历史并更换令牌与 MLS。不承诺远程销毁旧密文。见 [D-041](../../context/decisions.md#d-041双人恢复后其他旧设备必须重新授权)。

## 验收

- 本地归档、双人恢复协议、创建/邀请/遮蔽/入口与隐藏兼容入口均已接入产品。
- 首次访问无本机私密空间时不再经过旧三选一网关或遮蔽首页，直接进入欢迎页：创建私密空间、设置访问密钥、邀请页二维码+对方状态、打开链接加入、庆祝后可选遮蔽。欢迎页无「我有邀请链接」。
- 首次创建和恢复的网关页面直接替换，不保留上一页文案参与动画；其他产品子页面继续沿用既有方向动画与不透明目的画布。邀请页不再展示邀请编号或底部连接文案；二维码与复制仍使用包含完整高熵能力的真实链接。复制成功以 toast「链接已复制」提示。受邀方的系统访问密钥请求在可信点击栈内启动，且非受信任 HTTPS / 不支持 WebAuthn 时显示明确原因。
- 复制邀请链接只写入完整链接并留在邀请页，不隐式调用系统分享。恢复码在弹窗中输入并自动聚焦；可见前台的恢复码输入在该弹窗仍挂载期间可交接窗口失焦，收起键盘不离开当前页；`hidden`、`pagehide`、冻结和显式锁定仍失败关闭。
- 聊天顶栏最左侧常驻恢复盾牌，点击进入保存恢复码页；未完成准备时有底色与呼吸光圈。「我／电路图／对方」在上排，在线状态在下排；爱心与折线保持 PR #172 之前大小，折线连上左右在线呼吸灯。“给下次见面，留个入口”是消息列表内仅本机可见的私密空间小助手卡片，不写入服务端消息、密文历史或未读状态。
- 共同恢复开始页可选择只恢复我、只恢复对方或两人；打开恢复邀请的协助方不再选择范围，沿用发起方已选范围，先停在确认页，点「输入恢复码，立即恢复」后再弹出输入框。协助对方仍须先解锁自己的现有私密空间。恢复码弹窗使用多行输入并提供返回。等待页展示范围、设备和参与状态，不显示核对编号，二维码保持可读，无核对勾选、取消、手动刷新或「开始恢复」；双方恢复码均通过且范围未改时自动完成双签名。对方改变范围时发起方必须重新确认；双方签名和旧设备撤销边界不变。主按钮确认或自动完成即表示理解旧设备需重新授权。
- 「我的恢复码」页只保留恢复码状态与保存入口；「备份/恢复聊天记录」从聊天「更多」进入。新流程页使用不透明画布，底栏按钮上方无分割线。添加到主屏幕／书签优先打开系统分享面板，网页不能直接写入主屏幕或书签。
