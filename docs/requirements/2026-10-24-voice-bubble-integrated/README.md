## 当前方案与依据

保留微信语音气泡的声波图标＋相邻秒数、收发镜像与按时长有界伸缩，外观采用当前文字消息的 R16 与说话侧底角 R6、系统字体、收发颜色和主题。浅色发出 #e0ffc6、收到 #fff；深色收到 #342234，发出沿用 #944cd5 / #9349f4 / #3768ff 的聊天渐变。V2.3将声波、时长、时间与原回执放在气泡内部同一横排，时间／回执位于最右端，仅以较小字号和基线略下移形成偏右下感觉，不另开一行。收到顺序为声波→时长→时间；发出为时长→镜像声波→时间＋原回执，声波与时长仍相邻，元数据预留独立水平间距。时间约10–11px，视觉基线目标下移3–4px；主体回归紧凑40px、操作热区至少44px，通过增加短语音最小宽度而非堆叠高度容纳元数据。正式几何待验证和设计确认。状态含义不变、不新增已听回执。文字消息元数据沿用src/styles.css的既有位置，本轮仅修订语音单行布局。

播放以同一声波图标的轻量动画表达，闲置和暂停均静止，准备可用同图标弱化／轻量动效。无三角播放键、暂停键、进度或加载圆环；正常状态无已暂停、正在解密或解压等过程文字。真正失败保留必要原因与重试，辅助技术名称保留。

依据：PRODUCT.md 的 Voice Messages、DESIGN.md、src/design-tokens.css、src/design-system.css、src/voice-messages.css 和 src/lib/voice-player.ts。旧微信式V1.1由 docs/requirements/2026-10-23-voice-quality-bubble 拥有，本稿只修订视觉和过程文案；背景沿用既有主题方向，无新增品牌方向。
