- 设置「关于」新增「用户反馈」，独立页有必填邮箱、必填多行正文及提交按钮，正文最多 5,000 字。
- 格式校验原位提示；提交中禁止重复操作；失败保留本次输入并允许重试；成功明确已收到并可返回设置。

- 提交失败保留当前页输入；离开页面或锁定即清空草稿，不写本地存储。反馈最多保留 10,000 条，达到容量拒绝新增并保留旧数据；本期不自动删除、不增加删除或回复界面。
