## 范围与行为

1. 终止接入反馈为denied时替换整个聊天页面，标题「此设备无法进入密室」，不保留消息、输入框、在线状态或返回聊天入口。只有「返回密室列表」按钮。普通断网沿用可离线聊天行为；升级与空间不可用保留各自现有反馈。
2. 新密室以三步说明：请对方从「设置 → 帮对方进入密室」选择待接替设备生成链接；本设备当前浏览器打开新链接；对方回到聊天页保持打开直至连接成功。明确所选旧设备会失去收发能力。
3. 本机历史、草稿及待发密文保留，禁止新发送，待发内容不自动迁移到新设备身份。旧格式沿用已有设备生成添加链接、安全码核对及批准的边界，不套用新版自动接替说明。
4. 接入失效提示以当前设备ID绑定的本机标记加密保存在保险库，刷新、解锁或从列表再进同一密室仍为独立页。该标记只用于本机呈现，不是成员事件，不推断移除人或原因，不改变成员列表、私钥、服务端授权或恢复能力。
5. 打开有效新链接仍按现有接替流程执行，必须服务端接替成功并使用新设备凭据后才进入聊天；旧提示标记不能阻止新设备身份。其他密室不受影响。
