## 已确认方案与边界

原实现仅在进程内保存从在线到离线的转换时间，重启与内存淘汰使记录变空。现为每个空间、每个参与者角色保存一个最近确认聊天在线时间，不保存访问日志。

进入聊天立即记录；在线 pong 每角色至多每 30 秒落盘一次；离开／断开立即更新。任一有效设备仍在聊天时角色保持在线；历史时间不会恢复实时在线状态。空间删除级联删除记录，备份按既有保留策略管理。停机或崩溃只保留最后真实观察，不推测精确离线时刻。记录来自服务端时间及已认证设备，待批准、撤销、恢复暂停的设备不能刷新它。已有缺失记录不从后台认证时间补造，下一次进入聊天后建立。

实现采用兼容新增 SQLite 表，原 WebSocket presence 帧结构保持，旧客户端仍能读取；旧服务回退保留但不维护新增记录。无消息协议、加密格式、依赖或部署配置变化。服务端写入失败保留上次成功记录并输出固定错误，不在关闭／心跳回调抛异常导致服务退出。
