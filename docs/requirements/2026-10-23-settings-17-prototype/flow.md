# 业务流程图 V1.2

可视版本：[打开流程图](prototype/flow.html)。每个流程中的按钮可跳到同版原型。
所有创建、设备、验证和恢复结果均为模拟。身份与密码学契约由 NEW_ROOM_ARCHIVES.md、SECURITY.md 拥有。

## 创建与进入

```mermaid
flowchart TD
  A[点击创建密室] --> B[当前主题与双对话品牌过场]
  B --> C[准备本机密室]
  C --> D[建立加密保护]
  D --> E[核对服务端就绪状态]
  E --> F{真实创建已完成且最少准备时间已满足}
  F -->|尚未完成| G[图形保持闭合并展示当前等待状态]
  G --> E
  E -->|失败| H[图形保持闭合并提供重试或返回]
  H -->|重试| C
  F -->|完成| I[双对话图形打开并轻微向内推进]
  I --> J[聊天内稳定的密室就绪与邀请区域]
  I -->|减少动态效果| K[直接淡入聊天]
  B -->|锁定或隐私遮蔽| L[立即显示安全表面并停止装饰动效]
```

```mermaid
flowchart TD

```

## 恢复凭证

```mermaid
flowchart TD
  A[设置中的恢复凭证] --> B{是否已经回验成功}
  B -->|否| C[设置独立凭证密码]
  C --> D{两次输入一致且满足长度要求}
  D -->|否| C
  D -->|是| E[完整导出页]
  E --> F[导出凭证原图]
  F --> G[独立回验页]
  G --> H[选择已保存原图]
  H --> I[立即显示读取状态与缩略图]
  I --> J[输入凭证密码并验证]
  J -->|失败| K[页内说明并允许重新选图或重试]
  K --> H
  J -->|成功| L[标记已设置]
  L --> M[凭证管理页]
  B -->|是| M
  M --> N[导出凭证]
  M --> O[修改凭证密码]
  O --> P[核对原密码与二次确认]
  P -->|取消| M
  P -->|成功| E
```

首次设置密码后不强制设置或重复验证应用锁。改密保留原密码与旧凭证失效确认，真实能力轮换和原子保存仍按安全契约；原型不实现这些安全能力。再次独立导出、改密所需的既有操作认证不由本原型的无锁模拟状态证明已删除。

## 聊天记录恢复

```mermaid
flowchart TD
  A[聊天记录恢复独立页] --> B[选择凭证原图]
  B --> C[本机读取并显示缩略图与文件信息]
  C -->|格式错误| B
  C --> D[输入对应的凭证密码]
  D -->|错误| E[原位错误并重试]
  E --> D
  D -->|正确| F[独立恢复进度页]
  F --> G[认证目录并统计总量]
  G --> H[逐项校验聊天与原文件]
  H --> I[完成后统一提交]
  I --> J[完成页与五类数量]
  J --> K[回聊天查看仅本机历史]
  F -->|取消| L[确认取消且不发布未完成内容]
  H -->|网络失败| M[失败说明与重试入口]
  M --> F
```

## 设备与帮助对方进入

```mermaid
flowchart TD
  A[本人设备列表] --> B[标题右侧新增设备]
  B --> C{本人设备少于三台}
  C -->|否| D[上限说明与移除旧设备入口]
  C -->|是| E[点击复制设备加入链接]
  E --> F{应用锁是否已开启}
  F -->|否| G[先设置应用锁]
  G --> E
  F -->|是| H[验证本次应用锁]
  H -->|取消或失败| E
  H -->|通过| I[生成并复制设备加入链接]
  I --> J[在自己的其他浏览器打开]
  J --> K[新设备进入密室]
  L[帮对方进入密室] --> M[选择具体旧设备]
  M --> N[确认替换后果]
  N -->|取消| L
  N -->|确认| O[生成并复制进入链接]
  O --> P[对方新设备打开]
  P --> Q[发起方在前台聊天等待连接]
  Q -->|成功| R[仅撤销指定旧设备]
  Q -->|失败| S[保留旧设备并允许重试]
```

V1.2 用户明确：生成的是设备加入链接；生成前验证应用锁，新端不再核对安全码。重新复制同一链接不等于重新生成。本轮仅模拟该交互，不执行真实成员授权。

## 数字密码布局

```mermaid
flowchart TD
  A[设置或验证数字密码] --> B[保留上方锁图标及提示文字]
  B --> C[六个圆点与下方键盘和操作整组上移约16px]
  C --> D[输入六位数字]
  D --> E{设置还是验证}
  E -->|设置| F[再次输入并核对一致]
  E -->|验证| G[验证当前应用锁]
  F -->|失败| D
  G -->|失败| D
  F -->|通过| H[返回来源页]
  G -->|通过| H
  C -->|取消| H
```
