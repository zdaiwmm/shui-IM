# 业务流程图 V1.1

可视版本：[打开流程图](prototype/flow.html)。每个流程中的按钮可跳到同版原型。
所有创建、设备、验证和恢复结果均为模拟。身份与密码学契约由 NEW_ROOM_ARCHIVES.md、SECURITY.md 拥有。

## 创建与进入

```mermaid
flowchart TD
  A[点击创建密室] --> B[全屏暗铜双门场景]
  B --> C[准备本机密室]
  C --> D[建立加密保护]
  D --> E[核对服务端就绪状态]
  E --> F{真实创建已完成且最少准备时间已满足}
  F -->|尚未完成| G[门保持关闭并展示当前等待状态]
  G --> E
  E -->|失败| H[门保持关闭并提供重试或返回]
  H -->|重试| C
  F -->|完成| I[双门打开并向内推进]
  I --> J[聊天内稳定的密室就绪与邀请区域]
  I -->|减少动态效果| K[直接淡入聊天]
  B -->|锁定或隐私遮蔽| L[立即显示安全表面并停止装饰动效]
```

## 设置导航与媒体

```mermaid
flowchart TD
  A[聊天页] --> B[设置顶部抽屉]
  B --> C[独立设置子页]
  C -->|返回| D[恢复设置列表位置]
  D --> B
  B -->|点击手柄或上滑或 Escape| A
  C --> E[当前页面背景与顶部安全区同步]
  A --> F[点击胶囊进入相册与文件]
  F --> G{是否有内容}
  G -->|无| H[剩余内容区域居中显示空状态]
  G -->|有| I[内容列表]
  B --> J[切换密室]
  J -->|选择| A
  J -->|标题右侧新增| K[创建流程]
```

## 恢复凭证

```mermaid
flowchart TD
  A[设置中的恢复凭证] --> B{是否已经回验成功}
  B -->|否| C[设置独立凭证密码]
  C --> D{两次输入一致且满足长度要求}
  D -->|否| C
  D -->|是| E[完整导出页]
  E --> F[导出凭证原图]
  F --> G[独立回验页]
  G --> H[选择已保存原图]
  H --> I[立即显示读取状态与缩略图]
  I --> J[输入凭证密码并验证]
  J -->|失败| K[页内说明并允许重新选图或重试]
  K --> H
  J -->|成功| L[标记已设置]
  L --> M[凭证管理页]
  B -->|是| M
  M --> N[导出凭证]
  M --> O[修改凭证密码]
  O --> P[核对原密码与二次确认]
  P -->|取消| M
  P -->|成功| E
```

首次设置密码后不强制设置或重复验证应用锁。改密保留原密码与旧凭证失效确认，真实能力轮换和原子保存仍按安全契约；原型不实现这些安全能力。再次独立导出、改密所需的既有操作认证不由本原型的无锁模拟状态证明已删除。

## 聊天记录恢复

```mermaid
flowchart TD
  A[聊天记录恢复独立页] --> B[选择凭证原图]
  B --> C[本机读取并显示缩略图与文件信息]
  C -->|格式错误| B
  C --> D[输入对应的凭证密码]
  D -->|错误| E[原位错误并重试]
  E --> D
  D -->|正确| F[独立恢复进度页]
  F --> G[认证目录并统计总量]
  G --> H[逐项校验聊天与原文件]
  H --> I[完成后统一提交]
  I --> J[完成页与五类数量]
  J --> K[回聊天查看仅本机历史]
  F -->|取消| L[确认取消且不发布未完成内容]
  H -->|网络失败| M[失败说明与重试入口]
  M --> F
```

## 设备与帮助对方进入

```mermaid
flowchart TD
  A[本人设备列表] --> B[标题右侧新增设备]
  B --> C{本人设备少于三台}
  C -->|否| D[上限说明与移除旧设备入口]
  C -->|是| E[复制设备加入链接]
  E --> F[新设备打开并申请]
  F --> G[已有设备核对两端安全码]
  G -->|一致并批准| H[新增独立设备]
  G -->|拒绝或不一致| A
  I[帮对方进入密室] --> J[选择具体旧设备]
  J --> K[确认替换后果]
  K -->|取消| I
  K -->|确认| L[生成并复制进入链接]
  L --> M[对方新设备打开]
  M --> N[发起方在前台聊天等待连接]
  N -->|成功| O[仅撤销指定旧设备]
  N -->|失败| P[保留旧设备并允许重试]
```
