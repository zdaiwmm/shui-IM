### V1.2 设计修订（快照 f1be890）

- 创建过场回到产品 P1 的背景、当前主题色与 `private-dialogue-v9` 双对话标志。直接沿用 `src/lib/entry-art.ts` 中的品牌路径；两侧对话图形打开及轻微推进表达进入密室（V1.3 已取消推进与透视变形），不切到独立游戏世界。
- 普通主题和深色主题都保持当前页面颜色；三阶段、慢网络、失败、减少动态和成功衔接行为保留。当前总时间约 4.9 秒供审阅，真实业务就绪仍是进入聊天的前置条件。
- V1.1 暗铜／黑石门氛围探针由内建 imagegen 生成，仅作本地预览；用户反馈风格差异过大，V1.2 不采用。V1.1 源码已保存为 `1281b9c`，不是已确认设计。当前原型不依赖图片资产。
- 遮蔽样式不加可见标题／名称／对勾或热区文字标注。缩略图和实际演练共用真实错误页面文字、图形及布局，按当前预览视口等比缩放。右下角 80px 热区透明，与现行页面一致。
- 添加我的设备仅保留说明和“复制设备加入链接”主要操作。首次点击先验证应用锁，通过才生成并复制；取消或错误不生成。未开启应用锁先设置，已生成链接可再次复制。新浏览器打开即可进入，不再核对安全码。三台上限和历史边界保留。
- 设置关闭手柄仍为 40×5px、44px 热区，改用明确底部定位，距面板下边缘 8px。V1.1 的居中叠加 padding 使实际下边距过大，已按用户批注修正；8px 是本原型目标，不声称为 Apple 指定尺寸。
- 数字密码页沿用 `numeric-password.css` 的灰底、圆键、标题与尺寸体系；六个圆点、键盘、底部动作及提示作为一组上移。常规高度与对比状态相差 16px，短屏保留适配。原型同时覆盖设置两次输入与设备链接操作验证。

### V1.3 当前设计修订

- 创建入口和 loading 共用同一个 `.portal-scene`、背景与品牌元素；点击“创建密室”只更新原位状态，介绍与按钮淡出，原按钮位置接出圆环 loading，没有横向切页、插入新创建页面或突然放大 logo。原型新增可点击创建按钮以完整审阅这段衔接。
- 删除三段横杠，以连续旋转圆环表示等待，准备完成换为勾选。保留阶段文字、慢网络持续等待及失败重试；原型的时间轴只供审阅，不表示真实进度百分比。减少动态时圆环静止，文字继续说明状态。
- 品牌外框和整体固定尺寸、原始比例；取消透视翻转和整体推进，内部双对话只各向外轻移至多 3.2px。成功时整个创建表面淡出露出聊天，不使用空白遮罩中转。减少动态只保留淡入淡出。
- 回验页删除“系统分享或导出返回不代表已保存……”说明；回验成功才设为已完成的模拟行为保持。
- 数字错误替换圆点上方原有提示，保留原提示区域的高度。错误时六点保持填满并左右衰减抖动 360ms，随后清空；键盘和页面不抖动。减少动态改为轻微明暗反馈。重输第一位恢复正常提示；设置两次不一致与应用锁验证错误共用反馈。
- 相册和文件的整组空状态在剩余区域几何中心上移 24px，以更靠上的视觉中心展示；短屏内容仍可滚动。
