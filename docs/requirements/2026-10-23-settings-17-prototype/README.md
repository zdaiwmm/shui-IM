### 新增过场方向

- 场景：两人在白天或夜晚用手机进入私密聊天。普通页面沿用 P1 的浅深色和四套配色；创建这一短暂仪式使用固定暗铜色场景，门缝暖光提供期待感。
- 参考：本产品已确认 P1；原生设置的层级导航；用户指定的经典端游开门进入体验。只提取双门重量、门缝光与向内推进，不借用现成游戏素材。
- imagegen 内建工具生成过一张双方向氛围探针，左侧暗铜门、右侧极简黑石门。本轮选择左侧的厚重门体、暖光和对称构图用于原型；最终选择由用户审阅 V1.1。探针是预览材料，未作为产品／原型依赖或大图提交。
- 保留的视觉要素：厚重双门、闭合时细窄暖光、静态刻线、少量尘埃、开启后向内的空间感。原型用本地 SVG 几何与 CSS 透视表达，未栅格化核心界面。
- 准备最少 3.6 秒，三阶段各至少 1.2 秒；准备完成后约 960ms 开门，最后 340ms 衔接聊天。实际最少总时长约 4.9 秒，真实业务完成是开门前置条件，不能以动画定时器代替。此时长是 V1.1 待确认设计目标。
- 慢网络保持当前准备状态；失败不打开门，提供重试／返回。减少动态关闭尘埃和空间推进，仅保留文字状态与淡入。隐私遮蔽／锁定正式实施仍须立即安全表面，不等待动画。
- 原型控制提供播放、暂停、时间轴与开门关键帧，便于审阅运动。

- 待确认规范差异保存在本记录：完整回验子页、已完成管理态、首次流程不强制应用锁、新开门过场、设备／密室标题操作、手柄比例。进入正式实施后再同步长期 DESIGN、PRODUCT、安全契约与移动规范，当前不能把目标改写为已实现事实。
- 首次凭证密码后直接导出／回验，不自动设置应用锁、不重复验证应用锁。原凭证改密、旧卡在线读取能力失效确认及真实原子轮换不由原型模拟替代；本原型默认无应用锁，不证明后续独立操作的既有认证要求已全部删除。
