# mijiu.cloud 家庭 Compose 迁移

2026-11-09 用户在本次迁移会话确认实施：家庭共享 Ubuntu 上为 Quiet Room 单独建立 Compose 项目和空库，Lead 沿用现有部署。东京保留 Nginx、证书、Xray、TURN 和现有 FRP。独立隧道只在东京回环提供新上游，切换前保留原上游。家庭宿主禁止安装整机 Docker 存储维护入口或改动 Lead 的 Docker 配置、挂载、网络及服务。

实施基线为 fe27143c，拟迁移应用为东京现网 2d900665。主程序与备份使用独立有界加密存储。家庭后端签发东京 TURN 的短期凭据。发布保留精确 CI 配置摘要验证、维护门、单写和独立公网回读。切换失败先关闭新写入，确认是否有真实新数据再决定回退。范围不含个人主站或管理域名。

核验：专用 FRP 已双向认证，东京回环到家庭合成响应已通过。家庭 Docker 29 使用 containerd 镜像存储，Lead 演练容器已存在。准备和旁路证据不等同正式切换或端到端通话验收。

## 共享宿主约束

家庭端经已验证来源单独安装 Ubuntu Nginx 程序，运行私有回环 gateway，由东京承担 TLS。网关保留应用真实维护门与 WebSocket 升级。专用部署身份配置启用 sharedHome，部署时校验独立加密卷挂载和 root 管理的 Compose 补充文件；同一覆盖层用于正常更新与回滚。外置 TURN 使用东京中继，不在家庭机占用公网通话端口。整机存储维护工具禁止安装。

仅在显式 sharedHome 模式下，若 Docker 返回清单摘要，需从本地 containerd 读取对应清单、重新计算 SHA-256，再匹配 CI 记录的配置摘要；保留原有归档校验、提交和平台检查。未知的清单格式拒绝发布。
