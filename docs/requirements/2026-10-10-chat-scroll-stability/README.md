## 已确认方案

首次进入无保存位置时定位最新，再次进入恢复本机阅读位置。底部收到消息继续跟随，历史阅读收到消息保持位置并使用既有新消息提示。主动新发送恢复最新，发送后手动上滑立即取消旧跟随；旧发送、上传、重试与回执不得覆盖更新的用户操作。键盘开合、多行输入、媒体加载及分页保持底部意图或历史消息及屏幕偏移。被删除／隐藏的锚点选择本机可读邻近消息。点击返回最新补齐后续本地历史，可由用户中断；引用返回保留原位置。

- 范围：聊天定位决策、异步发送／媒体／语音完成的定位归属、邻近锚点恢复、对应浏览器专项与产品约定。
- 取舍：沿用原消息节点、输入框与顶部栏；使用操作版本使过时的异步完成只更新内容。媒体预览只消费一次主动发送定位，上传完成与重试遵循当前阅读意图。保存跟随意图不再另用 48px 几何阈值推断。
- 排除：不修改加密、原子持久化、消息 ID／重试、已读协议、设备历史边界、依赖或生产配置；不增加视觉体系和界面入口。
- 设计依据：PRODUCT 的 Message Timeline／Conversation Continuity、DESIGN、src/main.ts 样式入口及现有 chat-layout／chat-interactions／desktop 样式。用户明确豁免原型与流程图，本需求不生成这些材料。
