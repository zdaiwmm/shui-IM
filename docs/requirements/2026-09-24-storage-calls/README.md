## 范围和方案

1. 自动备份三日恢复点，数据库独立快照，附件只在备份区内复用；原件与备份不能硬链接。失败残留、校验、并发和删除边界一起处理。
2. 本机加密显示副本与原件缓存统一预算1GiB；图片高质量副本、视频封面、语音原字节、已打开文件最多128MiB。缓存故障不得影响消息与密钥持久化，不进云恢复包。
3. 在线消息循环保持每会话512MiB/10万条，须具备安全缺口同步、去重和控制状态；完整协议验证前不得启用淘汰。
4. 通话复用现有已审阅coturn部署路径，填充生产中继配置并验证真实中继媒体；不新增第三方信令服务，不降低通话身份/加密验证。
5. 当前磁盘主要占用来自Docker层和备份；空间治理与发布预检分别取证，不能把消息循环当作当前释放数GiB的方案。
