## 方案与边界

- 备份容量默认strict不变：至少8GiB、磁盘／inode低于80%。Mac安装器可显式选择reserve并把策略写入本机LaunchAgent；未设置为strict，未知策略／无效预算失败。服务器与传输头不能切换本机策略。
- reserve按实际可写空间准入，逐文件预留完整剩余文件及8GiB，每16MiB复核，独立磁盘复读后／原子发布前再次检查。传输仍限64KiB写入块、单文件256MiB、总量12GiB及10万文件；SQLite、所有密文附件、路径、摘要、会话绑定和新鲜度校验保持不变。
