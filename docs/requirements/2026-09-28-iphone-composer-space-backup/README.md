## 边界

- 沿用现有界面和按钮。目录同步不转移设备私钥、原空间访问令牌、MLS 状态或历史；独立管理密钥不能授权建立成员。
- 原设备上线且已验证时自动补齐其同凭据的旧待建立空间授权；不同凭据／已建立空间不自动准备。原设备从未同步过授权时不能凭空间名称删除。
- 断网不假装删除成功；目录版本冲突重试有界；并发加入及失效签名失败关闭。
- 同目录的新空间可以显示名称，但不同浏览器请求根下的成员请求仍需要有效授权。
