## 实现与验收

- 解锁时并行恢复本机可见页、投影、待发与回执。按页读取当前密文并核对与本机加密校验记录的绑定，命中时仅解密投影事件及需比较的副本。历史缺失、密文损坏与副本冲突仍阻止首屏。首次打开或页内容变化时逐条认证，独立本地密文最多同时解密八条。
- 多设备通过原有链路按序补收；空回执批次减少无效列表重绘。以三台独立密钥设备、跨密钥更新及多页积压验证首条本机消息与最后一条远端消息可见，并在补收期间输入草稿。网络和本机存储事务失败后核对完整持久序列。
- PC 回复在打开引用栏之前移除菜单预览并显示真实气泡；菜单其余元素按现有方式退场。桌面浏览器连续采样选中气泡和邻近气泡，容许 1 CSS 像素的舍入差。
- 测试入口为 `reaction-history.e2e.mjs`、`old-device-catchup.e2e.mjs` 与 `frontend-lifecycle.e2e.mjs`。自动化使用合成消息与本机服务，未采集用户设备数据；实际设备、广域网时延及生产发布分别核验。
