## 本次设计

沿用此前本聊天生成的浅色三状态效果图和项目 P1 规范。图片／视频状态固定右下；表情状态固定透明底部信息行；媒体、信息行和相邻消息几何稳定。

V1.1 变更：准备、上传、等待服务确认、失败、重试均不显示时间。仅消息获服务端确认保存后，在预留的时间槽中淡入发送时间；时间仍取消息 sentAt，不伪造确认时刻。上传100%不等于已发送。

正常上传使用真实阶段的模拟进度；未知比例只显示旋转环，断网只显示静态等待。成功后单勾，已有读回执才双勾。失败原位重试，同一条演示消息恢复，不插入第二条。为比较展示而重复的周期是演示重置，不代表生产自动重发。

媒体预览与发送事实分离，完成不自动解除模糊。热区44px、固定24px状态行、完成20px视觉体量；状态只改变透明度和进度，不缩放消息。
