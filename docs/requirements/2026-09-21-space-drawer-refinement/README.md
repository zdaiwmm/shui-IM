## 已确认交互

1. 内缩悬浮抽屉，当前空间以大字号独立置顶，其他空间在下方切换；不显示文字头像或逐行卡片。底部为创建按钮和独立设置图标。
2. 其他空间显示本机最近已解密消息的预览与未读角标，媒体使用 `[图片]` / `[视频]` / `[表情]`，语音和其他文件使用对应标签；零未读隐藏，超过 99 显示 `99+`，辅助功能保留完整数字。待加入空间保留等待提示。
3. 鼠标 hover 只改变文字与箭头，触摸不使用大面积 hover 背景。
4. 长按、右键或 F2 在名称附近打开“编辑空间名称”；点击立即聚焦改名弹窗输入框。名称为 1–40 个字符，仅修改本方名称，保存后保留列表位置。
5. 创建入口直接启动必要的系统访问密钥设置，成功后展示邀请半屏弹窗；失败可重试或返回原空间。复制仍沿用真实邀请和现有剪贴板保护。关闭、点遮罩或下拉顶部把手保留待加入空间，可从列表重新打开。
6. 设置分为当前空间、本机、关于；隐藏滚动条但允许滚动，移除功能说明入口，统一方形细线图标。在线样式有在线胶囊、心动按钮两个可选预览，支持方向键与返回保留。
7. 聊天名称收进左侧入口，12px 次要文字，长名称省略，完整名称用于辅助功能。默认在线胶囊居中；可选红心在右侧 44px 按钮内居中，保留双方在线和消息动画语义。

## 消息与隐私边界

- 一次只解锁并运行一个空间的会话。2026-09-22 起，抽屉不再标注“上次打开”；其他空间的预览是该空间在本机已解密历史中的最新可见消息，包含尚未阅读的消息。打开抽屉时，若该空间使用当前已解锁的设备通行密钥，会在本机重新读取其历史，不推进阅读游标，也不把正文发到服务器。
- 已解锁期间，创建新空间和切换到同一通行密钥保护的空间不再额外创建或验证设备密钥。锁定后重新进入仍需验证一次。密钥不同的旧空间会在下一次打开时改用当前设备密钥包裹。
- 快照取自本机加密历史的最新页，按聊天相同的删除／隐藏规则投影，不展示相册专属、控制事件或引用中的旧内容。预览最多 160 个字符，只密封在本机空间目录。
- 当前设备的独立未读观察令牌仅允许 GET 数字。抽屉打开时刷新其他空间的未读数，关闭或锁定后停止；不推进阅读游标。离线保留最后确认数，撤销响应移除观察令牌。
- 云端目录采用显式字段白名单，不含本机预览、设备槽位或观察令牌；恢复读取同样剔除这些字段。替换本机端点不继承原端点快照。未扩展普通新增设备的历史边界。
