范围内保留：无账号双人空间、每人每空间三设备；各浏览器独立消息加密状态；新端没有加入前历史或旧回复预览；双方恢复码及明确签名批准；目录认可与逐空间对方授权分离；普通添加与修复原批准主体。重试复用原ID／密文、原任务及原身份，不重复推进棘轮。

排除：J1名称辨识需用户验证、O1备注字段尺寸为可选调整，均不在本批正式修改；不新增账号、群组、历史自动迁移、真正撤销待加入事务、恢复码远程销毁、分析服务或生产发布。

关键取舍：前台恢复缓冲只为同一次读取重试，不写明文存储、日志或诊断。已提交共同恢复／设备申请仍按现有加密状态续接；锁定不是撤销。接入终态消息不得据未认证网络文本修改本地成员链、删除钥匙或绕过接入授权。

原型对新邀请的处理采用保守提示：当前声明／签名任务保持不变，新邀请未打开，完成后需重新打开，不长期保存第二份原始邀请。这避免新增隐私持久化与跨目标队列；正式调度仍须回归其他既有邀请种类。
