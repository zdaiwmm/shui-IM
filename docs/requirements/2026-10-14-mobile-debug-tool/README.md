# 移动调试工具固化 V1

## 身份与当前阶段

- 类型：开发工具与跨电脑接续；仅调试外壳涉及页面，非正式产品 UI。
- 起始规则：本机 main `4356531cea264dd01bd9110da90b9ff62cfd7a59`；任务／实时 main 基线 `1c9d4f9def848e31b397375e900df5d28d576e6a`；分支 `codex/local-mobile-debug-20261013`。本机 main 落后，任务基线与实时远端一致。
- 当前阶段：已由PR #288合并，精确main完整CI、固定生产发布与独立回读通过。实际工作树绝对路径与端口仅在本机核验，不作为跨电脑配置。

## 方案与设计材料

将当前临时调试方案保存为 `tools/mobile-debug`、`scripts/dev-mobile.mjs`、项目级 Skill 和[操作规程](../../workflows/mobile-debug.md)。启动入口为 `npm run dev:mobile`；显式选择回环端口，使用独立本机数据，不迁移证书、密钥、邀请、恢复材料或保险库。保留居中、1px 边框、最多100%比例、移动 UA／DPR3／5点触控参数、Safari 风格系统栏和模拟键盘。

已审阅外壳来源是本会话实际运行的 Safari 风格本地入口。代码原型继续沿用同一外观，不新增产品视觉方向。键盘通过仅作用于本调试 iframe 的合成 VisualViewport 联动；不是 Safari/WebKit、原生 IME 或真机证据。7条产品批注归[独立需求记录](../2026-10-14-mobile-debug-feedback/README.md)。用户随后明确免除原型，授权直接实施及交付；本工具直接加载正式应用。
