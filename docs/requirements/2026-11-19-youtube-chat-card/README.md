# 聊天中的 YouTube 视频卡片

2026-11-19 用户确认接收方无法访问 YouTube 时仍应能在聊天里播放，并确认由 yt-dlp 解析、mijiu-server 上的 AIX 按需转发。沿用现有卡片交互与播放鉴权。

- 支持公开的 YouTube 普通视频和 Shorts。聊天内展示标题、频道、封面、时长、简介和原链接。草稿预览可移除；旧设备只接收普通链接。不能播放时保留原链接。
- 消息只加密保存原链接和卡片标记。接收方解密并看到卡片后，浏览器经同源鉴权网关提交视频 ID 获取公开信息，打开记录时不会提前请求视频。AIX 只接收视频 ID 与操作，不接收房间、设备或聊天信息。图文在 AIX 进程内短期缓存，客户端只在当前卡片使用。
- 点播时 AIX 通过发起解析时使用的出口读取兼容的 MP4，沿用短期票据和单段 Range 读流。关闭、离开聊天或锁定时停止播放。视频以流传输，服务器不生成完整视频文件，聊天不新增附件。
- 开关、依赖和验证入口见 [AIX 服务](../../../services/aix-x/README.md)及[连接说明](../../../deploy/aix/README.md)。公网启用范围以转发许可、实际出口测量和生产确认结果为准。
