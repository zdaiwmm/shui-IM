# 聊天顶栏提示与消息渐变

2026-11-10 用户在设计对照图中确认「按照 A 方案实施」。此前确认提示始终撑满在线状态左侧剩余宽度。方案 A 使用右侧圆点向左展开，文字上提后上下合为细线。规则来源 e5297664，任务基线 85ba90ad，分支 codex/chat-notice-rail-20261110。

## 位置与流程

顶栏从左到右依次为提示、在线状态、设置。设置与在线状态共享原有定位。提示按行内剩余空间分配宽度，34px 底板对应 44px 点击区域。紧凑心形和标准在线状态使用同一布局。子页反馈由当前可见页面承载，保留返回、关闭操作。

```text
收到提示 → 按优先级选取一条 → 320ms 向左展开 → 显示
    普通反馈到时 → 文字上提、190ms 收成细线 → 恢复仍有效的提示或留空
    更新 → 保存草稿 → 重新加载；保存失败显示错误 → 恢复更新入口
    多个待办 → 查看详情 → 执行所选原操作
    进度改变 → 原位刷新文字
```

版本更新、历史加载、续传、视频任务、备份、导入、接入受阻、故障以及创建者首次相册引导均使用该位置。长反馈可打开全文。减少动态效果时只做短淡入淡出。暗色发送气泡共用一个渐变场，顶栏以上和输入栏以下分别延续首尾色。

设计依据见 DESIGN.md、移动视觉规范和会话中的三方案可播放对照图。正式实现只带 A。本次授权涵盖实施、验证和主线交付；生产切换另行确认。


## 验收

真实建房浏览器流程覆盖 320/390px、标准与心形在线状态、34/44px 尺寸、错误插入和更新恢复，并在深色发送气泡的渐变首尾两侧比较像素。P1 控件专项覆盖短屏、计时、遮蔽与强制颜色。更新说明、故障处理和视频恢复操作复用各自的发布更新、故障反馈与链接视频专项。物理 iPhone 待验。该变更涉及跨页呈现，云端执行完整应用回归。
