## 目标与范围

用户要求按六项体验建议执行，特别避免闪屏、UI 闪现和元素位置错乱。目标是保护阅读位置，让输入、发送、引用、菜单、媒体和表情切换连续，并让用户能中途取消或反向操作。

| 项目 | 本机基线事实 | V1 行为与实现方向 |
| --- | --- | --- |
| 键盘与阅读 | iOS 历史聚焦跳到最新消息，键盘打开时纵向触摸松手后收键盘 | 聚焦保持原阅读锚点，键盘打开仍能滚动消息；系统支持范围内衔接收起，不模拟控制 UIKit 时钟 |
| 发送连续性 | 本地持久化后插入消息，可见内容平移 280ms | 原子持久化不变；提交草稿、输入框收缩与消息位移协调；连续输入按版本保护；从当前画面接续动效 |
| 回复往返 | 有滑动回复和原消息跳转，未见返回来源栈 | 页面内有限返回栈；原消息不可用留在来源；关闭回复保留输入焦点；滑动取消不提交 |
| 新消息与阅读 | 已有阅读锚点、到底部与媒体占位 | 历史不被拉走，新消息提示与跨设备未读分离；底部自然跟随；用户向上滚动解除跟随 |
| 菜单与媒体 | 已有菜单源气泡保护与媒体查看 | 保留原节点和阅读位置，菜单边缘定位，关闭后恢复焦点；关闭共享元素动效仅在来源仍有效时增强 |
| 表情与键盘 | 已有面板保留及连续发送 | 切换保持草稿、分类及滚动位置，媒体占位不变；失败原位重试；快速反向操作不被旧回调覆盖 |

本轮覆盖上述六项，正式实施优先顺序为键盘与阅读、发送、引用往返，再完成剩余三项及组合回归。排除通话、空间管理、恢复、账号／设备模型、密码学协议、生产发布、装饰性全屏特效及新的外部服务。

## 关键取舍与兼容边界

- **明确的行为变化**：聚焦不跳回最新消息会替代 [D-032](../../context/decisions.md#d-032iphone-键盘开合与底部消息联动) 中这一条旧约定，也影响 D-034 对它的沿用。键盘打开时允许滚动会替代 PRODUCT.md 当前的手势门控。只在本原型呈现新方案，正式契约待第二次确认后随实现同步。
- 发送仍在本地加密原子持久化成功后清空已提交草稿，不把按钮反馈冒充成功；离线等待与服务端确认分开；重试复用原 ID 和密文。
- 引用只读本机已授权历史；不从新回复携带旧内容。返回栈只在当前解锁页面内有效，换空间、离开聊天及锁定清理。正式实现须处理来源删除、历史窗口切换和迟到加载结果。
- 顶部栏与输入框持续绘制，避免为了隐藏错误位置而闪现。输入框底边是尺寸变化时的稳定参照，不复用旧顶部坐标推算新高度。
- 布局先计算并同步提交，再用 transform 补间；不要同时让 CSS transition、WAAPI 与 viewport 回调争夺同一元素。中断先采集当前已绘制位置，再取消旧动画，旧完成回调须校验所有权。
- 不动画化整页高度，不重建消息列表／textarea，不以整元素 opacity 处理键盘过渡。动效通常 160–260ms，减少动态效果直接落到最终态。
- 缺失原图来源或低能力环境采用直接关闭。隐私清理立即生效，绝不等待退出动画完成。
- 原型滑动回复阈值为 64 CSS px，用来审阅触发反馈；正式阈值需真机确认。不会把原型参数视作已批准生产参数。
