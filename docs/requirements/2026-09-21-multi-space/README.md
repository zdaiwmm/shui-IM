## 方案

- 目标：打开邀请进入目标空间，而非被浏览器现有空间带回旧会话；同一浏览器的空间独立保存并能快速切换。
- 入口：聊天页左上角原盾牌入口改为空间抽屉；原右上角“…”取消，其入口转入抽屉二级设置。默认保留当前在线胶囊，可选择右上角爱心按钮。
- 抽屉：空间列表独立滚动，选中行加高；普通空间只显示名称，待加入空间增加主题色提示。底部固定浅色“创建新空间”和醒目的玻璃“设置”。点击空间切换；长按或桌面右键仅出现“编辑空间名称”，本次没有删除功能。
- 设置：二级页面包含当前空间的设备管理、备份数据、恢复数据；本机的我的恢复码、在线样式、遮蔽；关于中的功能说明和更新日志。返回列表保留阅读位置。
- 创建：从抽屉进入时创建页第二按钮是“返回”；无本机空间的首次入口及丢失恢复场景保留“恢复私密空间”。创建成功新增独立空间并生成邀请链接。
- 在线爱心：左半代表对方，右半代表自己；单方在线时对应半心高亮，双方在线时合拢并心跳，消息由发送者一侧触发电流。默认样式仍为现有胶囊；选择只影响本机。详细动效须以可交互原型与正式浏览器验证为准。
- 数据与恢复：升级前唯一保险库应无损成为一个空间；各空间独立身份、密钥、历史、待发和运行状态。本机空间集合用一个总恢复码作为统一入口，但各空间仍按其独立恢复协议取得双方确认；旧恢复码须保留过渡兼容。失效邀请不能回落到旧空间；标签页不得跨空间覆盖。总码泄露扩大已备份空间的暴露范围，这一取舍需在正式实现的安全文档中明确。
- 排除：空间删除、真实生产发布、将模拟原型连接真实聊天或恢复服务。
