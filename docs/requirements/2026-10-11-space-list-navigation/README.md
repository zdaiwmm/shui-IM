## V1.1 已确认方向与当前原型

基于现有不透明 P1 视觉，手机端用完整空间列表页替代左侧浮动抽屉。聊天标题栏左侧“空间图标＋当前名称”打开列表，中间保留在线胶囊，右侧直接进入设置；心动样式时爱心与设置并排。窄屏截断名称并保留完整无障碍标签。

列表顶部提供返回、创建、设置。所有空间采用紧凑双行（V1.2 为 68px 起、40px 头像），当前项以淡色背景与勾选标识，不再放大当前标题或分“当前／其他”组。保留本机快照预览、未读数、待加入倒计时与浏览器授权入口。设置沿用现有完整页面与功能分组，返回原入口及原滚动位置。桌面保留 1024px 起的 280px 可收起双栏，并复用相同行样式。

切换已授权空间先模拟原验证，成功才改变当前空间；取消／失败保留当前空间与草稿、阅读位置。受限／尚未准备的空间进入无聊天内容的访问外壳；不会通过选择列表授予权限。原有创建邀请、改名和待加入空间删除仅作合成演示，实际授权与服务端删除边界沿用产品契约。

范围含空间导航、聊天顶部栏、设置入口与往返，以及 V1.2 新增的私有头像和两步创建流程。外观、在线样式、自动锁定及设备页仅为必要导航演示；其余设置入口只说明不在演示范围。不修改正式产品样式、路由、协议、存储、认证、依赖清单、部署配置或安全契约。

## V1.1 审阅调整

- 用户认为在线状态样式页此前的 UI 更好：恢复现有产品的两张可视化选项卡，展示“TA／爱心／我”胶囊与独立爱心，保留勾选、键盘选择和“查看聊天效果”。不恢复旧抽屉导航。
- 用户指出浅色模式下未选中控件呈深色：按现有 `applyAppearance` 的方式，将原生 `color-scheme` 与实际页面模式同步；未选中单选控件恢复空心外观。
- 用户要求屏幕顶部与浏览器底部栏分别衔接页面对应背景：手机入口默认完整页面，顶部安全区随标题栏，底部安全区随输入栏、访问页操作区或列表／设置底色。桌面提供“全屏体验”，切换页面和配色时同步底部画布背景。
- 延续现有透明 `theme-color` 与不透明页面边缘，通过贴近视口的标题／输入栏提供浏览器取色来源；依据 [WebKit 对边缘颜色延伸的说明](https://bugs.webkit.org/show_bug.cgi?id=301756#c2) 与 [安全区适配说明](https://webkit.org/blog/7929/designing-websites-for-iphone-x/)。此处为原型适配，Safari 原生状态栏／工具栏着色仍待真机验证。

## V1.2 创建流程与视觉修订

- 用户确认头像仅自己这一侧可见，与空间名称沿用同一私有存储／同步边界。正式实施时应作为加密的个人空间资料处理，不给对方共享头像，不作为认证或身份凭据；本原型仅用内存与本地 Blob 预览，不实现持久化或同步。
- 第一页只保留紧凑的头像／名称资料区与一条私有范围说明。点按头像打开贴底选择面板，可选默认图案或本地图片；支持关闭、Esc、遮罩、下拉关闭和焦点返回。图片为 JPG／PNG／WebP、最多 5 MB、居中显示；这些原型限制是本轮设计细节，不改写正式附件契约。
- 下一步进入独立通行密钥页。设备已有可复用密钥时显示确认复用；设备尚无密钥时显示密钥名称和可选设备备注。空间名称不会自动填入系统密钥名称。沿用当前 `src/app.ts` 的设备凭据复用模型，不强制每个空间创建一把新密钥，也不改变正式产品原有不支持／取消／失败的保护边界。
- 返回保留头像、名称及密钥页填写；取消／失败保留资料且不新增列表项；成功才添加待加入空间并展示模拟邀请。演示控制的失败分支提供一次模拟成功重试，刷新和重置清除演示数据与已登记的 Blob。
- 用户指出交互显旧、视觉未严格遵循规范后，移除常驻图案选项、编号步骤和重复说明，把选择收进头像面板，把主操作固定在底部；不扩大两步创建与头像私有的业务范围。
- 对照 P1 及正式组件修正：聊天以外的标题栏使用中性页面表面并居中，聊天继续使用既有聊天标题颜色；标题 17px／600、设置正文 14px／400、普通主按钮 14px／600，设置图标底 24px／图形 17px，图标配色沿用正式设置分组；分组圆角 10px。
- 空间列表使用 14px 名称／12px 预览，双行 68px 起、40px 圆形头像；授权按钮有色部分 32px，点击区域 44px。外观和自动锁定普通选项行 44px，设备信息行 56px；文本放大或换行可增长。在线状态两张已确认选项卡保持原结构。
- 全屏入口沿用 P1 的 VisualViewport 高度／偏移适配，内容独立滚动，底部操作区随可视区域；只验证桌面浏览器短视口与计算值，不宣称真实 iPhone 键盘通过。
- 简单确认对照 P1 使用约 280px、14px 圆角、分隔的横向 44px 操作；复杂改名表单和邀请保留各自容器。头像面板沿用 18px 顶角、32×4px 装饰柄与 44px 操作触区，桌面居中。
- 视觉以 [P1 原型](../2026-10-10-ui-system-exploration/prototype/README.md)、[DESIGN](../../../DESIGN.md) 和 [正式组件](../../../src/design-system.css) 为准。头像动作选择补充参考 [Apple Action sheets](https://developer.apple.com/design/human-interface-guidelines/action-sheets) 的动作选项模式；不引入新的视觉方向或玻璃效果。
