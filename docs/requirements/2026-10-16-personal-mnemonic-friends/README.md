## 已确认的需求方向

1. 产品服务已有信任关系的两个人的极私密聊天，采用邀请加入；不提供公钥搜索、公开用户资料、好友申请或好友列表。个人身份用于连续性、授权与恢复。
2. 个人身份采用常用的12个英文助记词；支持生成新词或导入已有12词，包括钱包助记词。默认建议使用聊天专用助记词。本期不做钱包接入、外部支付、资产或群聊。
3. 首页提供“创建密室 / 恢复密室”。A生成后保存并核对，或导入本人助记词，生成时完成本机三词保存检查、导入时验证完整12词，随后直接进入待加入聊天页，日常解锁与入口遮罩移至聊天系统卡片引导，无昵称/头像步骤。A复制邀请发给B；B加入前不能聊天。
4. B打开邀请，生成/导入本人身份，已有可用本机身份则复用。B请求进入后，A聊天页才显示本次验证码。A通过双方原有可信渠道确认并另行告知B，B输入后完成加入。
5. 在新设备验证完整助记词，恢复本人身份与未关闭的会话目录，日常保护移至进入聊天后设置，进入旧密室仍需对方批准当前设备。不能通过历史恢复绕过批准。
6. 任一参与者可关闭已加入的密室，必须验证本人助记词。关闭后双方入口移除，停止聊天/通话，保留服务端加密数据。个人身份保留，可以建立新密室。
7. 已关闭密室需要双方分别在自己的设备验证各自的助记词，并确认同一次恢复请求，才重新出现并恢复各自有权限的历史。不收集或互相交换助记词；单方导入身份不自动复活密室。
8. 不硬性限制同一身份同时只能有一个空间。保留现有多空间创建逻辑/数据；当前仅隐藏额外创建入口，未来再接付费与权限检查。
9. 用户最新要求：空间列表入口本期保留在设置中，便于测试与已有多空间切换。
10. 支持现有空间迁移：原设备逐空间解锁，双方分别绑定个人身份；等待期间旧空间继续可用。多个旧空间保留各自历史、角色，不合并。
11. 本期保留原保险箱创建者权限。关闭不删除保险箱加密数据，共同恢复不扩大权限。
12. 聊天是主页面，无底部导航，无左上返回。聊天顶部只有两个覆盖在背景上的44px挂件按钮，无整行标题栏；分别进入设置和锁定（未设置解锁时先进入设置），次级页面返回按钮放在底部。日常遮罩不展示身份、空间、未读或历史预览。

### V3六项批注与保存核对说明

用户本轮要求身份来源半屏化、导入标题改为“导入助记词激活身份”并用12个编号格、解释本机核对三个词、解锁/遮罩移至聊天引导、验证码改4位四格、聊天顶部移除整行标题栏。本次只授权继续调整原型与流程，尚未确认正式实施。

生成助记词后的三词核对保留为本机保存检查，改随机抽取三个不同位置并固定本次题目，返回重看或填错不重新抽题。它帮助发现漏存/抄错/顺序错，不能证明全部12词已可靠备份；不能把答对3词作为服务器认证。真正导入需检查完整12词的词表/校验和，再本机派生身份并签名；服务器仅接收公钥、绑定请求的签名和必要加密数据/元数据，不接收助记词/根私钥，不存助记词哈希作为登录口令。标准依据为[BIP39](https://github.com/bitcoin/bips/blob/master/bip-0039.mediawiki)，三词抽查本身是产品交互建议，不是BIP39要求。

本机保护延后后，V3采用待审策略：未设置解锁前仅在本次页面临时使用，刷新/关闭需要助记词恢复；配置后才加密持久化必要本机材料。系统卡片明确告知后果，稍后设置不阻塞邀请/聊天；设置内随时可补齐。服务器加密目录的初始写入、失败回收、未设置时的会话/历史生命周期及恢复批准仍需在正式安全方案中冻结，不能默认明文落盘。原型始终为内存状态，即使显示设置成功也不实际保存。

四位码可用空间为10000种，用户指定长度已落实；正式验证必须绑定原邀请、身份、设备、目标密室和单次挑战，并限制跨请求累计猜测。当前5分钟/5次和恢复15分钟仍属待审参数。所有助记词输入页复用12个编号格，包括导入、恢复、关闭确认及共同恢复；支持从某格起批量粘贴，数字码支持自动跳格、空格删除回退与一次粘贴。

## 交互细节与安全边界

- 助记词：正式目标为BIP39英文12词，恢复个人身份；助记词不等于所有消息密钥。设备随机密钥、独立MLS状态和原有设备权限边界需保留，不直接把助记词当消息密钥。
- 验证码：绑定密室、受邀身份、设备和单次请求；在A本机临时卡片显示，排除聊天历史、备份和通知。用户指定4位数字，原型采用四格输入/四数字展示；建议5分钟、最多5次错误，均为V3待审参数；4位仅有10000种组合，正式实现需跨请求累计限速、冷却、抗重放与并发占位处理；不能更换请求无限猜测。原渠道的联系人判断是现实身份确认的必要部分。
- 邀请：打开或链接预览不消耗名额；加入成功后旧邀请和验证码失效。拒绝、取消、超时不会授权，重新申请得到新码。
- 关闭：明确为可共同恢复的关闭状态，不称永久销毁。正式实现需将关闭、服务端授权停用、双端目录移除及待处理任务失效一致落地；离线副本/截图/导出无法由UI保证远程擦除。
- 共同恢复：两份身份签名/证明绑定同一密室、同一请求、有效期和明确意图，助记词仅本机处理。原型建议15分钟，拒绝/撤回/过期后保持关闭并重新验证。不得用一次旧身份验证无限期重新开密室。
- 保险箱：关闭保留数据与原角色；本次未另增关闭后保险箱独立入口，也未扩大受邀方权限。
- 导入：原型只接受对应A/B的无效演示词，任何真实词不进入真实恢复。钱包种子导入风险提示只在导入页展示；不做钱包支付功能。
- 隐私入口：原型仅演示中性遮罩、显式解锁及手动锁定，不验证真实后台自动锁定、平台认证或系统缩略图。隐藏入口不代替认证，也不能保证外层WebView、浏览器历史或操作系统不留痕。
- 新设备：先恢复身份/目录，逐密室对方批准后才显示旧消息与允许发送。取消、拒绝、过期和锁定不自动批准；普通身份恢复不展示已关闭密室。
- 旧空间：模拟原设备解锁、本人绑定、等待对方绑定、保留原空间；QR3/QR4兼容仍须原恢复授权，不能只换身份字段取得旧权限。
