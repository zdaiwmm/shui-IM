## 范围与方案

1. 图片消息带引用时，引用与图片共同参与正常流；图片尺寸上限只约束图片，不限制整块气泡高度。覆盖图片、视频、相册、表情与失败反馈的相邻消息布局。
2. 滚动帧即时更新气泡渐变，即使键盘／手势账务仍等待终态；不改变锚点和未读语义。
3. Chamber设备管理使用当前房间状态，避开停用的旧新增设备接口；保留当前／对方设备和既有移除能力，撤下新增设备和旧说明。旧版待批准／修复协议兼容不扩大。
4. 数字密码设备不显示通行密钥管理；通行密钥页唯一功能为名称修改，保留原指定凭据重新验证、提供方更新及本地保存一致性。
5. 通行密钥页沿用520px内容轨道、26px标题、20px边距、44px主／返回动作及8px间隔，无多余功能解释。
6. 设置入口统一为「入口遮蔽页」；子页含独立开关和可扩展的样式列表，目前仅遮蔽层缩略图。保存失败回滚原开关；遮蔽不替代认证。
7. 「关闭这间密室」成为独立危险设置项；从备份与共同恢复移除，完整助记词确认、关闭／恢复协议不变。
8. 设置撤下恢复其他空间入口及其导航处理；首页恢复空间及现有本人／双人恢复保留。
9. 切换空间列表恢复固定底部新建空间动作，复用现有创建流程。
10. 撤下通知管理及文案管理的应用路由；已有通知传输／旧订阅兼容测试保留，不新增通知订阅。
11. 在线胶囊／心动按钮选择均应用到Chamber聊天；预览复用现有SVG组件，子页无右上关闭，选择即时生效并留在本页，可返回设置。
12. 浅色返回按钮增加中性填充和边界，表情入口选中态增加主题色填充／内描边。
13. 工具到表情直接交接，不先启动键盘交接；Emoji不等待收藏／合集读取，图片延迟解码。
14. 每次隐藏媒体重新绑定已验证的本机Gaussian预览；48px等效模糊和隐私生命周期保持。
15. 语音裁剪使用实时轨道坐标及最新合并指针样本，结束时提交最后位置；避免每个移动样本都重置无源播放器。独立44px外向热区、边缘竖线、最短区间、只发选区及失败重试保持。
16. 三步引导助记词文案改为「密室进不去时，用它找回并恢复记录」，已查看状态保留。
