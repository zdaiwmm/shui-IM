## 本版确认对象

**统一改造自动锁定、临时遮蔽和恢复规则**：按设定的空闲时长保护当前解锁运行期；真实本机操作续期，固定最后 10 秒显示全局小气泡；整个气泡背景就是进度，文字为“即将锁定”，右侧为蓝色小“延期”按钮。确定离开、主动锁和安全失效优先。移除与这套规则竞争的旧失焦遮蔽、短期续接及分端空闲锁。

适用当前浏览器内已认证的私密空间列表、聊天、设置、抽屉、保险箱、附件／阅读器及弹窗，不绑定爱心或某个页面。待接入空间的已验证浏览器目录也受同一空闲策略约束。未验证网关不展示私密正文，不运行一个可以续期的已解锁授权。管理员独立站点的认证策略不在本次改造内。

## 统一计时、续期与设置

1. 成功通过当前保护方式验证后，建立内存中的截止时间；建议默认 **1 分钟**。已有密码保护仍用原密码，通行密钥保护仍用原通行密钥。验证失败、取消、超时或晚到结果不启动授权。
2. 空闲时长建议提供 **30 秒、1 分钟、2 分钟、5 分钟**；不提供永不锁定。入口为“设置 → 自动锁定”。用户已要求可设置，四档与默认值已随 V6 确认。
3. 截止前的真实本机操作按“现在＋设定时长”重新计时，不累计叠加。包括点击／触控、有效键盘输入、中文输入、编辑／粘贴、搜索、选中／复制、滚动／拖动、导航、查看附件、设置与辅助技术激活。只有网页内可观察的操作计入，浏览器地址栏等系统 UI 操作无法作为应用续期事件。
4. 单纯悬停／移动、自动滚动、布局、网络心跳／重连、回执、历史／重复消息、上传／下载／备份进度及程序事件不续期。辅助技术激活不能仅凭 `isTrusted` 一个判据排除，正式实施需覆盖。
5. 任何事件处理前先检查期限。到期事件与输入／消息／延期同时发生时，到期优先；不允许晚到操作复活授权。锁后只接受有效的新验证。
6. 建议偏好仅保存在当前浏览器，本机空间共用，不同步对方或其他设备。跨标签可共享偏好，但不共享解锁证明和活动续期。保存成功立即按新时长重新计时；取消保留旧值；失败保持编辑态且沿用旧值；非法值回退默认。已有标签读取外部偏好变更本身不是活动，新的设置不能追溯延长它当前的期限，下一次真实操作才按新值续期。
7. 页面挂载、重绘、刷新数据不新建期限。用户主动导航属于操作；切换空间仍遵守目标空间原保护，旧空间资源清理与写入归属不变。
8. 手动锁建议放在现有空间菜单，名为“立即锁定”，不新增常驻浮动锁图标。主动锁的优先级高于弹窗、通话和延期。

## V6 全局小气泡

- 剩余时间大于 10 秒：完全静默，不新增标题行、固定底部占位或可见常驻倒计时。
- 固定最后 **10 秒** 出现 **“即将锁定【延期】”**。提醒时长不可设置、不可关闭。气泡视觉高 28px，实际触控范围至少 44px；延期用与发送按钮同源的蓝色实底小按钮样式，视觉约 20px 高。
- **整个气泡背景为进度填充**，从满格向零平滑收缩，比例为 `remaining / 10`；取消独立横条和动态外框。背景低饱和、文字与延期按钮位于填充之上，不闪烁、不变红、不跳秒、不发声或震动。reduced motion 取消插值过渡，但计时仍继续。
- 到期前点延期按当前设置重新计时并立即隐藏提示；其他真实操作也相同。忽略不延期、不增加宽限期。出现提示本身不是活动。气泡不提供容易误解的关闭按钮。
- 同一气泡整体可激活，蓝色延期是视觉动作焦点；不嵌套按钮，不把 20px 小外观做成难以点击的独立热区。出现不抢焦点；延期不收键盘、不滚动正文、不切页、不关闭弹窗、不透传给发送／保存／删除按钮。
- 聊天位于输入区上方；设置和阅读器位于当前可见区域下方，避开工具栏；弹窗内归属于当前活动模态语义树并避开操作区。遵循可见视口、安全区与滚动变化，极短屏可移至表面上部非交互位置。均不改变聊天内容高度。
- 恢复码等已有不可延长的显露上限保留。若更早触及该上限，临期显示实际更早的到期时间，并移除“延期”动作，明确该限制需重新验证；不能显示可延期按钮却仍因另一隐蔽旧计时器突然锁定。原型 `?cap=1&page=reader` 用虚构内容展示不可延期的敏感显示模式；不代表真实恢复流程或认证已经通过。

## 两项已确认的业务取舍

**接收消息：建议不独立续期。** 这是对用户最初“收消息也续期”的明确调整建议，已随 V6 确认。输入、发送、翻阅照常续期；对方无法靠一直发消息让无人操作的前台页面长期解锁。若用户仍选收消息续期，则仅首次有效、前台、未过期、认证解密持久化完成的实时聊天消息计入；重复、历史、回显、回执及重连补发排除。这一选择不能再承诺本机无操作达到设定时长必锁。

**持续媒体：建议真实前台使用期间暂停空闲期限。** 限已接通且仍有实际实时媒体的前台通话、正在进行的前台录音、用户主动启动且实际播放的有限音视频；媒体结束／暂停／错误／退出后按所设时长重新计时。等待接通、权限等待、静止预览、自动播放、循环／播放列表及后台播放器不享有豁免。确定离开／主动锁／撤销仍立刻停媒体并锁定。这允许前台媒体持续期间超过所设时长保持解锁，需确认体验取舍；严格方案则到期直接中断媒体。

## 场景与结果

| 场景 | V6 预期 |
| --- | --- |
| 连续聊天／长消息／设置／搜索／抽屉／图片／阅读器 | 本机操作续期，任意页面固定最后 10 秒同一气泡；静态阅读不动仍到期 |
| 普通 visible blur、点地址栏、原生键盘栏、系统菜单 | 不遮、不锁、不续期，继续原期限；focus 不重置时间 |
| 切换标签、浏览器后台或最小化且文档 hidden | 立即真正锁定，不等倒计时；返回重新验证，不复用 retainedSession |
| 桌面切另一窗口但文档仍 visible | 不猜测失焦原因，继续原期限；纯浏览器无法保证所有应用切换都可立即判定 |
| 文件选择／拍摄／权限／复制／分享／导出 | 发起的网页操作续期；外部面板等待不续期；操作超时只取消对应任务；hidden 或统一期限到期则锁，回来重验／重选，丢弃旧运行期结果 |
| 未解锁时的系统通行密钥提示 | 不被本轮 1 分钟空闲策略打断；沿既有有界验证、真实前台消费和取消／失效检查，不展示私密内容 |
| 新消息、断网／WebSocket 抖动、上传下载／导入恢复／备份 | 采用上节接收取舍；连接和后台进度不是人在场证据，不锁、不续期；安全拒绝和撤销单独立即处理 |
| 前台通话／录音／播放 | 按已确认持续媒体规则；离开和主动锁高优先级，晚到权限必须停轨道 |
| 刷新／关页／跳外站／freeze／BFCache 返回 | 保持／进入锁定；不持久化可复用解锁授权；返回不自动显示正文 |
| 休眠／系统锁屏／定时器节流或挂起 | 能接到离开即锁；无法执行时下一次运行、显示或操作前检查绝对期限，不能先闪正文再锁 |
| 多标签／多设备／对方操作 | 独立解锁和期限，A 的活动不续期 B；建议主动锁广播同保险库失效信号，只广播失效，不共享密钥或解锁权 |
| 空间切换／接入批准／撤销／销毁 | 原目标保护与运行期绑定保留；晚到批准不能绕过已到期期限，撤销／销毁不能用延期复活 |
| 恢复码及敏感管理操作 | 新鲜认证和不可延长上限保留；全局设置不放宽它们，不让不可延期的更早期限伪装成可延期 |
| 锁定时有文字草稿、待发消息、录音或文件 | 保留已加密文字草稿与已原子提交的密文待发箱；停止媒体，清理未提交明文文件／录音与 URL；必要时重选，不能承诺所有未发送素材无损保留 |

锁定先同步失效和关闭私密呈现，再异步清理；返回沿用原伪装页／解锁入口，不因提示新增另一种免验证恢复流程。保留原消息 ID、已生成密文及 MLS 原子持久化，不重复推进棘轮。服务端协议、密码学、设备历史边界与备份权限不因本次改造扩大。

## 实施结构与验收

- 应用级控制器集中维护锁定／验证中／静默计时／临期／持续使用／清理、期限、原因和运行期 generation；页面消费状态及提供锚点。旧日常隐私归属和短时续接不再并行决定授权；必要的操作超时与安全失效仍显式分类。
- 使用 wall clock 与 monotonic clock，以更早到期为准，防止时钟后调延长；轻量定时刷新仅服务视觉，不能以动画或 interval 次数作为权威期限。网络、解密、权限、发送和验证跨异步边界均复核原空间、generation 和期限。
- 真正锁定清理 DOM、明文引用、媒体轨道、临时 URL、阅读器 Worker、预览与未提交素材；密文草稿、持久待发箱及恢复任务沿原契约保留。不能承诺内存物理清零、防截图或后台缩略图绝不含内容。
- 正式实施需同步 PRODUCT／SECURITY 的隐私契约与相关决策，记录哪些旧取舍被 V6 取代；不修改协议或将聊天明文上传。

## 浏览器边界与设计材料

“稳定且不依赖失焦”和“任何切到其他应用都立即锁”在纯网页中不能同时保证所有窗口场景。可见失焦无法可靠证明页面已隐藏；因此本版采用确定的 hidden／生命周期立即锁和可见页面期限保护。后台定时器可能被节流，不能保证暂停时 JS 仍能执行或系统截图已清除。依据：[MDN Page Visibility](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)、[Window blur](https://developer.mozilla.org/en-US/docs/Web/API/Window/blur_event)。

- [交互原型](prototype/index.html)、[流程源码](flow.md)、[离线流程](prototype/flow.html)。离线直接打开，不需账号、编译或网络。`?board=1&theme=dark` 为总览；`?freeze=1&seconds=10` 为手动运行前的 10 秒状态；`?embed=1&freeze=1&page=settings&seconds=7&config=1` 为设置夹具；`&keyboard=1` 只是模拟键盘；`&duration=120` 预置 2 分钟。
