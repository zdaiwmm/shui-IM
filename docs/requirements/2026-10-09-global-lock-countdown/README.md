## 目标与设计结论

将日常自动锁定改成一个可以看见、解释和预测的规则：**成功验证后 60 秒，应用内真实操作续期至 60 秒，没有续期则到期锁定**。所有已解锁页面共享一个截止时间，应用顶边留白中显示不占布局高度的微型进度，按需展开秒数和主动锁定。

这会替换现有以可见页面失焦、短时遮蔽续接、移动 10 分钟／桌面 30 分钟空闲分流为核心的策略。不是在原有失焦判断上继续增加例外。已有隐私清理、认证、密文持久化和运行期失效机制仍需复用，避免改动密码学与协议。

当前实现及契约依据：[PRODUCT.md 的 Local Unlock and Privacy Curtain](../../../PRODUCT.md#local-unlock-and-privacy-curtain)、[SECURITY.md](../../../SECURITY.md)、[决策 D-005／D-048](../../context/decisions.md)、`src/app.ts` 与 `src/lib/privacy-surface.ts`。新规则属于待确认的产品与安全边界变更，设计材料不修改这些正式来源。

## 统一规则

1. **启动**：当前空间／当前保险库的原保护方式验证成功，并且允许呈现私密内容后，创建内存中的 60 秒截止时间。验证取消、失败、超时、过期或运行期被替换不启动。已有密码保护空间继续其原验证方式，不强迫迁移通行密钥；不降低敏感操作的再次验证要求。
2. **续期**：已解锁、页面可见、截止时间尚未到期时，真实本机操作将截止时间更新为“现在 +60 秒”。一次操作更新到 60，不累计成 120、180 秒。导航、点击、触控、滚动、拖动、有效键盘输入、中文组合输入、编辑、粘贴、搜索、选中／复制、附件操作和明确的辅助技术激活均包括在内。
3. **排除**：单纯鼠标悬停／移动、页面自动滚动、程序触发事件、轮播／心跳、重连、送达回执、在线状态、旧历史同步、消息重试、上传／下载／备份进度、定时渲染均不是本机用户操作。辅助技术不能只依赖 `isTrusted` 一个判据，实施需覆盖真实的可访问控件激活；原型仅模拟常见可信浏览器事件。
4. **到期**：权威剩余时间 ≤0 时同步关闭私密呈现并启动锁定清理。处理用户操作、收消息、网络回调和重新显示页面前均先检查到期；不能用一个晚到的输入／消息将已过期会话救活。重新验证成功才新建有效期。
5. **离开**：`visibilitychange → hidden`、`pagehide`、`freeze`、关闭／刷新、跨文档离开、运行期替换、主动锁定等硬离开立即锁定，优先级高于续期和媒体。BFCache `pageshow.persisted` 返回先保持锁定；不恢复原解锁授权。内部页面导航不等于离开，只按真实操作续期一次。
6. **普通失焦**：文档仍 visible 的 window blur／focus 不遮蔽、不锁定、不续期。浏览器地址栏、开发工具、系统菜单或桌面窗口切换导致的单纯失焦不再改变锁定状态。现有“是否实际聚焦”的已读／媒体已读条件保持独立，不因新规则把无人注视的消息标为已读。
7. **断网**：WebSocket 断开不锁定、不续期；用户仍可操作本机内容，发送沿原离线队列规则。连接恢复不延长授权。认证拒绝、成员撤销、空间销毁等安全失效沿已有策略立即失效，不能当普通网络断开处理。
8. **锁定后**：新消息、自动重连、重新聚焦、点击正文均不能解锁；私密页面与媒体消失，继续使用须用户主动验证。

### 收消息规则的选择

推荐 **本机用户操作续期，收到消息不独立续期**。连续聊天时，输入、发送、翻阅等操作已经续期；对方不能通过连续发送让无人值守的页面一直保持解锁。

若用户选择保留原设想，则只有 **前台、已解锁、尚未到期且成功认证／解密／持久化的首次实时聊天消息** 可续期。自己的本次发送只算一次；回显、重复投递、历史、重连补发、回执、心跳、控制消息均不续期。到期后的消息不得复活授权。此选择仍允许无人操作的前台页面被对方连续新消息延长，无法同时承诺“本机 60 秒无人操作必锁”。

### 持续使用与长操作

推荐明确、有限的 **使用中** 状态：已建立且仍在传输本机实时媒体的前台通话、实际进行的前台录音、用户主动启动且确实播放的前台音视频算持续使用。不要每隔几秒伪造用户操作；顶边细线保持填满；展开详情显示“正在通话／正在录音／正在播放 · 使用中”。结束、停止、暂停、媒体错误或隐藏前台媒体入口后，重新开始 60 秒；隐藏／离开仍立即锁定并停止媒体。

- 等待接通、权限尚未授予、打开但没播放、静止摄像头预览、自动播放、后台播放不享有此状态；等待接通与权限请求不自动续期。
- 不允许无限循环、自动播放列表或不可见播放器长时间维持解锁；循环默认不作为持续使用，后续明确播放仍受控制。
- 如果用户选择严格 60 秒规则，则取消使用中状态；无操作即锁定，通话／录音／播放会被停止。不能在界面承诺“不会打断通话”。
- 静态阅读不会自动续期；滚动／翻页／选择文字续期，长时间不动仍锁。浏览器不能确认人是否仍在阅读。上传、下载、导入、恢复和备份不是持续媒体使用，不暂停授权。

## 全局界面 V2：零新增高度与弱提示

用户对 V1 的明确反馈：新增一行压缩聊天区，键盘展开后更拥挤；不符合实际透明且元素少的标题栏；常驻强倒计时容易造成焦虑。本次只修订视觉呈现，不改变 60 秒、操作续期或现有业务待决项。

- **不新增标题行**：删除 V1 的 44px 状态行与 3px 全宽进度。全局指示器脱离文档流，放在应用顶边已有留白中央，视觉尺寸仅 **32×2px**；现有聊天标题区保持 72px 及透明背景。页内容与输入区不增加 padding／高度补偿；键盘展开时不另占一行，不增加可视区域损耗。
- **原有视觉语言**：聊天页保留左侧空间胶囊与右侧爱心，取消 V1 虚构的加粗产品标题／副标题组合及整行底色／分隔线。只有原有有界控件保留其材质；倒计时不接入爱心、在线状态或空间名。
- **弱化倒计时**：日常显示中性、细小的进度，不常驻盾牌、“自动锁定”字样、秒数或红黄绿全宽条。剩余长度仍代表 `remaining/60`；不做宽度过渡、闪烁、呼吸、脉冲、续期回弹或声音／震动。
- **末段提醒**：最后 10 秒细线采用低彩度暖色，尺寸与位置不变，不新增红色横幅或弹框。原先 30 秒绿色／黄色切换取消。这是根据用户反馈提出的 V2 取舍，尚待审阅；不是擅自确认新的业务规则。
- **按需查看**：视觉线有独立 44×44px 命中区，位于顶部中间的非交互留白。点按／键盘激活展开小详情，显示秒数、操作续期说明及“立即锁定”；再次点按、点外部、Escape 或“收起”关闭。点开和关闭均是用户操作，因此会续期至 60 秒，面板应如实显示新值，不展示点击前的过期数字。面板本身是浮层，不挤压聊天内容。
- **全局一致**：由应用外壳持有，所有已解锁的应用内页面、抽屉、阅读器、查看器及弹窗采用同一位置和同一截止时间，不因页面挂载重置。顶边留白若遇页面标题／控件冲突，应在既有 72px 标题范围内避让，不能以增加标题高度解决；实施需逐页验收。网页外的系统面板与原生全屏依然无法覆盖。
- **无障碍**：中性细线本身保证必要对比，不通过极低透明度隐藏；可访问名称与进度值提供剩余时间，不逐秒播报。不能仅靠暖色传达时间，长度与按需文本并存。细线不是拖拽把手；真实用户能否理解与发现入口仍需用户体验确认。减少动态效果保持无动画；锁定即时，不等待视觉结束。
- **锁定／持续使用**：锁定后移除进度，显示原锁定页；媒体持续使用的业务选择仍待答，若采用则详情显示“使用中”，不维持一个跳动数字。

## 场景覆盖与预期结果

| 场景 | 续期／锁定规则 | 锁定后的处理／返回 |
| --- | --- | --- |
| 解锁／验证中／取消／失败 | 仅最终有效验证成功建立 60 秒；其余保持锁定 | 主动重试；旧或晚到的验证结果不得重新开启已失效运行期 |
| 连续聊天、输入长消息、中文输入、编辑／粘贴 | 每次真实操作续期；发送点击已计入，不要求网络成功 | 已加密持久化的文字草稿按原契约恢复；并发到期时禁止先发后检查 |
| 新消息／突发消息／旧消息补齐 | 收消息规则待选择；旧历史、重复、回执、自动重试不续期 | 已锁定时不显露正文、不自动解锁；未读能力沿既有契约 |
| 设置、菜单、空间抽屉、保险箱、搜索、收藏 | 操作共享同一截止时间；自动刷新不是操作 | 全局细线持续可见；锁定关闭抽屉与私密菜单 |
| 内部返回／切换页面 | 用户操作续期一次；挂载页面本身不续期 | 同一空间与运行期共享；返回不新建授权 |
| 图片、相册、PDF／EPUB／文本阅读器 | 滚动、翻页、缩放等操作续期；静态阅读仍会到期 | 关闭查看器、终止解析／Worker、撤销明文 URL、清理画布／解码缓存；阅读锚点按原加密契约恢复 |
| 保险箱显露图片、复制、预览 | 主动操作续期；不影响既有默认模糊和历史边界 | 锁定恢复隐私显露状态；敏感恢复码等仍单独验证 |
| 文件选择、拍摄、权限提示、剪贴板／分享 | 发起操作续期；普通 visible blur 不锁；不增加无限免锁期 | 若实际 hidden／到期则锁、撤销原操作；回来重验与重选，不能导入旧运行期晚到结果 |
| 通行密钥系统提示 | 仅锁定入口／既有敏感验证流程保留其特定验证边界 | 提示取消不解锁；hidden 后晚到成功按原绑定条件拒绝，不扩大运行期豁免 |
| 前台通话、录音、音视频播放 | 持续使用建议待确认；等待接通与权限等待仍倒计时 | 离开／锁定同步停所有轨道与录音／播放；不得靠迟到权限回调重新开启 |
| 上传、下载、导入、恢复、备份 | 发起的真实操作续期；后台进度不续期、不暂停 | 中止或安全收尾沿现有原子契约；保留密文持久任务，不保留未提交明文文件／录音；解锁后必要时重选源文件 |
| 消息发送正好到期／排队重试 | 先检查授权；已完成原子提交的密文可保存；自动重试不续期 | 不重复推进 MLS、不生成第二个 ID；锁后迟到回调不得重建聊天 DOM |
| 断网、Wi-Fi 切换、WebSocket 抖动 | 不锁定，不续期；本机操作仍正常续期 | 原离线／重连机制，安全拒绝和撤销单独处理 |
| 切到其他标签页、浏览器后台、最小化且 hidden | 立即锁，剩余 59 秒亦如此 | 返回只显示锁定入口，重新验证获得 60 秒 |
| 桌面切另一窗口，但页面仍 visible | 不由 blur 锁定；继续计时，最多到当前截止时间 | 纯网页不能稳定判定所有“人已经离开”；此边界须明确接受 |
| 点地址栏、浏览器菜单、窗口短时失焦 | 不锁、不续期，时间继续流逝 | 回来不重置，已到期则验证 |
| 刷新、关闭、跳外站、freeze、BFCache 返回 | 锁定／下次打开从锁定状态开始；不得持久化可续用的解锁授权 | 新验证，不从 sessionStorage／历史快照恢复解锁 |
| 休眠、系统锁屏、定时器节流、进程挂起 | 能接收硬离开则即时锁；无法执行时在下一次运行、呈现或操作前检查绝对期限 | 不承诺系统休眠时 JS 仍能执行或截图已清除；回前台不得先闪现正文 |
| 手动锁定 | 立即锁；弹窗与媒体状态不能覆盖 | 主动验证再开；避免整条进度作为锁定热区导致误锁 |
| 同浏览器多个标签页 | 每份私密文档独立授权，活动 A 不续期 B；后台 B 锁定 | 用户主动锁定建议广播到同一保险库的其他已解锁标签，只广播失效信号，不共享密钥或解锁权限 |
| 空间切换／本机其他设备／对方设备 | 只对当前空间运行期授权；设备之间不共享倒计时 | 目标空间仍按原独立保护验证；本人其他设备／对方操作不续期本机 |
| 设备撤销、成员变更、空间销毁 | 已有安全失效优先；不以倒计时延缓撤销 | 立即清理，按原接入／恢复流程处理，不能通过续期复活 |
| 系统全屏播放器、辅助技术、放大文字、键盘 | 网页可控界面保留细线；系统界面无法覆盖；有效控件操作可续期 | 实施必须补真机与辅助技术验收，不以模拟键盘／浏览器通过代替 |

## 必须说清的浏览器边界

“稳定、不依赖失焦”与“任何切到其他应用都瞬间锁定”在纯网页中不能在所有浏览器／窗口场景下同时保证。网页能知道 hidden／pagehide 等状态；当桌面网页仍可见却失焦时，无法可靠区分地址栏操作、系统面板和真正离开。V1/V2 业务建议选择 **确定的硬离开立即锁 + 可见页面 60 秒授权**，不用 blur 猜测。如果要求所有可见失焦也立即锁，就会重新引入用户要解决的误锁来源。

同理，浏览器无法证明人仍在静态阅读，也不能保证系统在暂停 JS 或截取缩略图前给网页执行机会。本方案解决锁定的可预测性和受控授权，不宣称防截图、保证内存清零或系统缩略图绝不含私密内容。网页可见性与 focus／blur 的区别、后台定时器节流见 [MDN Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)；秒数与文本避免只靠颜色表达状态，依据 [WCAG use of color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)。

## 实施结构建议（尚未实施）

- 一份应用级授权策略控制器持有状态、截止时间、原因、当前空间／设备／运行期 generation 与媒体占用条件；页面只消费状态，不各自维护空闲计时器。最小状态：锁定、验证中、倒计时、持续使用、正在清理；清理中不可续期。
- 权威期限使用绝对时刻与单调时钟双检查，以更早到期为准；系统时钟向后跳不能延长，向前跳可以提前锁定。刷新后不恢复已解锁授权。进度渲染可 rAF／轻量定时器刷新，渲染暂停不暂停期限。
- 高优先级 hard departure／撤销先同步标记失效并关闭私密呈现，再异步收尾。检查授权贯穿异步边界；generation 不匹配的解密、选择器、媒体、发送与验证结果不得接入新的运行期。
- 锁定释放明文 DOM、内存引用、对象 URL、阅读器 Worker、媒体轨道、录音与未提交明文附件。保留既有加密历史、草稿、持久化密文待发箱和恢复任务；不能承诺所有未发送素材无损保留。草稿持久化竞态沿现有加密检查点机制处理。
- 续期由真实输入入口汇总，忽略程序回调；同一逻辑事件可合并渲染，但截止时间取最新真实操作时间，不能因节流丢失末次活动。管理操作的新鲜认证条件独立，不把 60 秒代替删除设备／恢复材料的专用验证。
- 旧 blur 遮蔽／续接策略与移动／桌面旧 idle 路径在本范围内统一替换，避免两套计时器竞争。焦点用于真实阅读、权限归属等其他契约时保留其用途，不能全仓删除焦点判断。
- 不以 WebSocket 作为人在场证据，不加新的服务端会话租约、消息明文或分析／远程脚本。
