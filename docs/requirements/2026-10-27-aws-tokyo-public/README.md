## 已核验证据与当前阻塞

- 选区测试：同组 15 个公共探针（大陆三网 9 个，海外 6 个），两轮共 180 个区域公共端点 HTTPS 请求；大陆与海外同等重要时东京为当前优先候选。测试没有创建 AWS 实例，不替代实际应用、WebSocket、吞吐、TURN 或长期可用性验收。
- DNS 查询：`shui.click` 权威域名服务器为阿里云；`chamber.shui.click` 尚无 A 记录。
- 候选精确 main [CI 40490796677](https://github.com/zdaiwmm/shui-IM/actions/runs/40490796677) 已成功；构建／单元集成、浏览器各组、通话专项、凭据扫描、依赖审计和 AMD64／ARM64 镜像任务均成功。实际发布前仍由固定入口复核最新匹配 CI 及产物。
- 当前 AWS 是新注册体验的受管理项目，项目默认地区为悉尼。东京 Lightsail 页面返回 403；GetBundles、GetBlueprints、GetInstances、GetKeyPairs、GetRegions 被上层服务控制策略明确拒绝。未尝试更换身份或绕过策略。
- AWS 官方[项目地区说明](https://docs.aws.amazon.com/accounts/latest/reference/project-regions.html)规定，这种项目按联系地址分配固定地区；使用其他地区需激活高级功能。
- [付费计划升级](https://docs.aws.amazon.com/accounts/latest/reference/upgrade-account.html)不可撤回，单独升级付费计划不提供高级功能；[激活高级功能](https://docs.aws.amazon.com/accounts/latest/reference/activate-advanced-features.html)需先升级，激活亦不可撤回，会移除项目费用硬上限，并需要管理账户邮箱验证及 root 密码设置。这些不是单纯购买所选实例的操作，须另行取得用户确认并由用户完成凭据设置。
