## 实施边界

- 主机容量程序 `deploy/server/quiet-room-capacity`：预检、监控、定向清理。失败关闭，不调用全量磁盘统计或全局 prune，不处理业务数据卷/连续备份。
- 发布前检查磁盘、inode、可用内存；构建前和停服前分别检查，保护发布空间余量。发布和定向清理共享文件锁。
- 依据成功版本登记保留当前及两个成功历史版本，所有容器引用与失败切换关联镜像额外保留。发布前快照保留最新三份，失败切换关联原快照额外保留。
- 每五分钟记录容量与备份新鲜度；每日低负载定向清理。告警渠道待用户选择，未接入外部通知时只能声称本地告警/发布阻断。
- 系统 journal 300 MiB/7 天，Nginx 每日轮转7份、20 MiB提前轮转；应用/备份容器每文件10 MiB、3份，需受控重建容器后才生效。
- 原建议在线清理7天旧构建缓存在此2 GiB主机执行后出现 SSH/公网超时；已经取消并明确禁止自动在线缓存 prune。后续缓存清理需维护窗口或迁移构建主机，不能因设了时间/大小过滤便视为低资源操作。
- 异地备份目的地和成功回执缺失；不伪造恢复能力、不缩减现有在线备份，也不自动购买资源。
