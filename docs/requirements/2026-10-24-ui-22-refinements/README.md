## 范围与验收
1. 在线状态样式页沿用统一 280ms 页面曲线和往返节奏。
2. 切换密室页面统一页面进入、退出节奏。
3. 设置页底部不出现遮挡列表的色块。
4. 进入子页面及返回保留设置列表位置，背景保持静止。
5. 我的设备标题与数量同行、规范刷新按钮、删除设备归属冗文及底部说明。
6. 对方设备采用相同标题与刷新位置；操作文案为「重新生成此密室进入的链接」；提示图标对齐首行。
7. 凭证管理入口不重叠，无多余外描边；所有输入占位文字常规字重。
8. 聊天记录恢复上传图标居中；删除 PNG 冗文；密码输入可辨识；按钮在物料卡外；上传后无读取进度条及重选按钮。
9. 在线胶囊呼吸灯在连线上方；缩短连线，文本略缩小。
10. 文字气泡内容及状态整体收紧横向留白，不重叠。
11. 媒体无左下角操作提示；占位图标居中；已开始状态过渡保证最低时长，未显示的过期状态合并；完成时间胶囊不重复留白。
12. 新增密室平顺进入创建页。
13. 创建页动画、标志与文字在同一区域，标志与状态字更醒目，重新分配间距。
14. 提交异常统一 toast；持续进度、安全说明保留内容语义。
15. 输入层打开期间锁定后方页面两个方向的滚动；编辑器自身输入、选择、必要滚动正常。
16. 导出第二步间距均衡；凭证图外无多余背景，图与页面有区分。
17. 回验页使用与第 8 项一致的物料、输入与操作布局。
18. 相册/文件 tab 按钮位于外框内并保留内边距。
19. 全屏媒体控件减少描边，显隐平顺淡入淡出。
20. 弱网提交先完成本机加密持久化，立即显示待发消息并释放输入；网络工作异步继续；不重复推进 MLS，不丢草稿。
21. 贴纸添加返回恢复原表情分类、内容和位置。
22. 自动锁定倒计时进度适度增强。
