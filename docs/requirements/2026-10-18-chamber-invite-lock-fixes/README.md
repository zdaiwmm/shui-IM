## 方案与边界

1. 过期邀请不显示「本次邀请已结束」或占用重发提示；主按钮为「邀请已超时，重新发起邀请」。重新发起成功立即生成新码及固定30分钟截止、轮换旧链接，自动复制新链接并提示结果。首次邀请仍从唯一占位计时。复制失败允许重试，不重复轮换已生成的邀请。
2. 数字密码键仅显示数字，普通进入／退出带页面过渡；隐私清理不等待动画。
3. 自动锁定改紧凑分组及按需时长选择，保留全部时长、三个独立开关及本机即时保存／失败回滚。
4. 遮蔽演练去掉顶部标题、底部返回和衬底；错误页位置正常，长按外围与指向引导更明确；完成弹窗的灰色「暂不开启」在左。
5. 顶部浮动设置及状态胶囊增加安全间距，外观缩小，点击目标保持至少44px。
6. 所有本机数字密码身份验证统一数字键盘，包括助记词、备份、设备、恢复及设置等；不转换旧长密码或原通行密钥。
7. 深色普通卡片及邀请方验证码改用底色和留白层级，去掉输入框式显示边界。
8. 已有本机身份加入邀请在同一有效操作只验证一次已有应用锁，不再设置新锁。操作证明仅用于该邀请、取消／隐藏／迟到结果失效，日常缓存不得解密根身份。
9. 验证码输入页后台切换后清除输入并按既有安全规则验证续接；排查卡死、崩溃及重复验证／轮询。
10. 有效期内邀请方验证码稳定显示；定时任务只更新必要状态，不重建整卡或重播动画。
11. Logo 循环播放，减少动态时静态，不阻塞页面操作。

设计依据：起始基线 `DESIGN.md`、`docs/design/mobile-visual-standard.md`、实际 `entry-experience.css`／`numeric-password.css` 与公共验证组件；产品／安全依据为 `PRODUCT.md`、`SECURITY.md`、`CHAMBER_IDENTITY.md`。本次确认替代原「数字键保留字母」「Logo 单次播放」「重发后等待占位才出码」及演练顶部标题／返回的相关呈现。
