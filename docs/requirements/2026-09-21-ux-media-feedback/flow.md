# 交互与诊断流程 S2

此图对应 [需求记录](README.md) 和 [可交互原型](prototype/index.html)。其中通话、上传、输入法候选及本机保险箱内容均为模拟状态，不能作为真实设备或网络验证。

```mermaid
flowchart TD
  A[无本机空间] --> B[创建私密空间]
  B --> C[设置访问密钥]
  C -->|成功| D[邀请重要的那个人]
  C -->|返回| A
  D -->|对方打开链接| E[有人为你留了一个私密空间]
  E -->|设置密钥并加入| F[聊天]
  E -->|暂不加入| A
  D -->|完成配对| F
  F -->|遮蔽演示| G[热区长按一秒]
  G -->|按住| H[心跳向外扩散]
  H -->|完成| I[选择开启或暂不开启]
  I --> F
  F -->|恢复入口| J[双方恢复码说明]
  J -->|验证设备| K[本设备恢复码]
  K -->|我已保存| F

  F --> L{聊天输入}
  L -->|组合期空格| M[候选词进入输入框]
  L -->|组合期回车| N[原始字母或文字进入输入框]
  M --> L
  N --> L
  L -->|组合结束后的单独回车| O[生成一条待发消息]
  O -->|服务器确认| F
  O -->|失败| P[原消息可重试]
  P --> O

  F --> Q[保险箱]
  Q --> R[相册或文件的本机记录先呈现]
  R -->|相册显示或隐藏| S[全部记录采用统一显隐状态]
  S -->|滑动至底部并上拉| T[自动载入更早项目并继承显隐]
  R -->|点开视频并播放| U[工具自动隐藏]
  U -->|点任意空白处| V[工具重新显示]
  V -->|再次点空白处| U
  R -->|长按照片、视频或文件| W[操作菜单]
  W -->|发送至聊天| X{附件可用且发送成功}
  X -->|是| Y[聊天列表新增一条消息]
  X -->|否| Z[保留源项目并提示重试]
  Y --> F
  Z --> W

  F --> AA[实时语音]
  AA --> AB[检查本机采集、信令、远端轨道、播放]
  AB -->|两端有声| F
  AB -->|失败| AC[呈现具体阶段与可用恢复动作]
  F --> AD[发送照片或视频]
  AD --> AE[准备、加密、分块、完成、消息确认]
  AE -->|完成| F
  AE -->|超时或失败| AF[同一消息身份重试]
  AF --> AE
```

补充约束：锁定、失焦或离开保险箱立即清理模拟敏感状态；真实产品实施时继续遵循现有密文验证、设备授权、恢复和历史边界。键盘候选的系统行为必须在目标浏览器实测，原型只展示预期结果。
