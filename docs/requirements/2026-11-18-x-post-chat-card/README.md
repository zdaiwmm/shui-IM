# 聊天中的 X 帖子卡片

2026-11-18，用户确认独立域名 `aix.shui.click` 的方案和移动端原型，要求实施，并进一步弱化视频分页。

## 交互

- 输入 X 帖子的可预览链接后显示草稿预览，发送时将作者、摘要和小封面作为有界快照加密。草稿来不及加载、帖子无法读取或有已授权旧设备时发送普通链接。
- 聊天卡片沿用消息气泡背景，只有视频封面有自己的画布。查看全文在原气泡中展开，可原位收起。全文由当前公开帖子按需取得。
- 播放按钮启动当前视频的内嵌播放。全屏按钮交给当前视频的原生播放器，退出后继续停留在同一视频。切换视频、离开聊天、遮蔽或锁定时清理活动播放。
- 多视频按照帖子顺序左右滑动，也可通过边缘按钮或键盘切换。只在封面角落叠小号页码，没有底色或独立分页栏。单视频隐藏切换控件和页码。

## X Article 与发送后解析（2026-11-19）

用户确认手机原型 V2 并授权实施，指定视频声音按钮使用图标。文章标题、作者和三行摘要直接放在原气泡。「查看全文」打开接近全屏的应用内阅读器。正文、标题、引用、列表、图片及图注沿用原文顺序和层级。引用的帖子及暂不可显示的媒体保留在原位置并提供 X 链接。阅读器独立滚动，关闭后保持聊天位置。普通帖的全文继续原位展开。

视频封面和播放器按当前视频尺寸显示。封面尺寸缺失时先显示播放控件，播放器取得媒体尺寸后更新画面。每次新建播放器默认静音，扬声器图标双向切换并提供读屏名称。

带文章的公开 `/status/<id>` 分享链接可读取正文。纯 `/i/article/<id>` 使用独立文章 ID，FxTwitter 的公开帖子入口无法用它查询，保留原链接。对于发送时尚无预览的 X 帖子，先按原流程发送链接，发送设备再查询并更新同一条气泡。输入框已开始的查询交给该条已发送消息继续使用。快照加密保存在该设备，保留最近 32 条。对端收到原消息。已有草稿快照继续随消息加密传递。发送者移除草稿预览后，直接发送原链接。

专项验收覆盖 AIX 公开性校验、有界富文本与图片、同源设备鉴权、320 至 390px 阅读和视频、发送设备原位补卡、对端无自动查询、重开恢复、遮蔽和锁屏清理。自动化入口为 `tests/link-preview.e2e.mjs`、`tests/x-post-gateway.test.ts` 与 `services/aix-x/relay.test.mjs`。

## 数据与服务

聊天网关先校验同源请求和设备权限。发给独立服务的数据只有帖子 ID、操作及必要的视频 ID。每个播放地址只授权所选视频，15 分钟内有效。浏览器通过该地址按需接收 MP4 字节，网关和播放器均不保存视频文件。加密消息中保留的图片预算合计为 16 KiB。正文首次展开和视频播放均重新验证帖子可读状态；已发送的摘要及封面属于本地加密历史快照。启用前若 X 的授权要求撤下或刷新已保存快照，需要先确认快照用途和保留方式符合授权。

2026-11-19，用户确认由 AIX 通过 FxTwitter 公开接口取得帖子正文和视频地址。AIX 向 FxTwitter 提交公开帖子 ID，查询无需 X API Bearer Token。视频仍通过原短期播放地址按需转发，只接受固定 X CDN 的 MP4。FxTwitter 查询失败时保留原帖链接。

浏览器和本地服务测试使用模拟 X API 和媒体响应。真实接入及生产启用分别依据[当前验证状态](../../context/status.md)和 [AIX 独立连接步骤](../../../deploy/aix/README.md)。

### 视频起播与内嵌播控

点按播放后，浏览器在请求短期播放票据的同时为 `aix.shui.click` 准备匿名连接。票据返回后才开始请求所选视频的字节。切换封面不会连接媒体域名，AIX 继续按需转发且不保存视频文件。

卡片内播放后显示简洁的暂停、进度和静音控件，触摸时按钮无白边，键盘操作仍显示焦点。全屏使用原生播放器。桌面 Chromium 和 WebKit 移动布局覆盖点击后取票据、切换、暂停、恢复及进度操作。真机 Safari 原生全屏和首帧用时单独验证。

性能基线为 `695eb8bc`。以桌面 WebKit 的 iPhone 视口，经生产网关取得票据并直接请求公网 AIX，对比同一公开视频。点击到首帧的中位数为 3.40 秒和 3.04 秒，票据返回到首帧为 2.01 秒和 1.78 秒。两组各发起 6 次，候选有 1 次未在测试时限内回传首帧，统计仅计入成功样本。

物理 iPhone（iOS 27.3、Safari）在同一 Wi-Fi 下对比线上卡片 `2026.11.19.1` 与实现提交 `f47964c2`，沿相同 AIX 链路各交替点播 5 次。点击到首帧的中位数为 4.03 秒和 3.14 秒，票据返回到首帧为 2.39 秒和 1.78 秒。确认内嵌暂停按钮无白边、暂停与恢复正常，点按全屏直接进入 iOS 原生播放器。退出回到卡片未在这轮确认。
