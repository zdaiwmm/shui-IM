## 已确认方案及边界

1. 首页去掉服务器密文说明，使用「创建聊天密室」「找回密室」，文案围绕日常中的隐蔽聊天入口。
2. 创建不再填写私有头像／名称，默认值仍可创建后修改。
3. 六位数字页称「设置应用锁」，能力提示仅首次创建且实际不支持时展示于底部。常用 iPhone 可见视口一屏，大字／极短视口保留可达性。
4. Chamber聊天标题去掉整条底色，右侧状态胶囊和设置独立固定悬挂。
5. 邀请卡去掉等待提示及可见请求编号，主文案「把邀请发给你想说悄悄话的人」。成功占位后出现四位码、复制、固定30分钟截止及重新邀请。内部请求绑定保留，未准备身份不得激活；轮换、五次错误和过期语义保留。
6. 定位邀请白屏，失败须有可恢复反馈。调查阶段尚未复现，不预设根因。
7. 我的助记词去顶栏、底部返回、品牌整体居中；身份重新认证、60秒显露及离开隐藏不变。
8. 入口遮蔽及自动锁定同样改为正文标题、底部返回。
9. 未配置的无操作倒计时默认关闭，保留明确保存值；息屏／切后台默认开并可独立开关。网页不能可靠区分两者，合为同一可识别场景；敏感内容隐藏、强制生命周期清理及重新加载后的验证保留。
10. 保留Chamber名称及P1主题，原创本地门廊／双人负形标志及约3秒有限动画；不阻挡操作，减少动态时静态呈现。

## 实施中追加 V1.1

2026-10-17用户在实施期间追加「自动锁屏中应该还要增加双击空白区域锁屏的的开关」，沿用本次免原型／直接实施授权。自动锁定页增加独立「双击空白区域锁屏」开关，默认开启以保留既有行为；只保存在本机，关闭不影响倒计时、息屏／后台及其他主动／强制锁。成功变更和跨标签页变更重置未完成双击，保存失败保留原值。增加偏好单测及真实指针／触摸开关回归。追加发生于完整浏览器回归开始后，第1条已加载的主流程仍检验不变的默认行为，受影响的双击／设置专项及最终CI另核对新候选。

追加开关后26项邀请／锁定／双击偏好定向单测及类型检查通过。首轮完整浏览器主流程在通话结束处遇到旧“默认30秒”夹具假设，尚未进入后续68条；修订为明确保存30秒以继续检验原通话到期行为，默认关闭由设置及Chamber专项单独验证。未修改生产通话或放宽到期断言。

完整浏览器续跑中主流程（含真实语音／通话）、移动调试和双引擎Safari专项已通过。旧空间创建取消夹具在动态载入编辑组件前读取返回按钮，出现null.click；补充等待真实返回按钮后续跑本入口及其余未运行入口，保留错误而不更改产品断言。

候选审查明确收紧离开锁定例外：仅普通会话可保留；敏感操作弹层、带认证标记的恢复／身份页及全部待创建／邀请／个人设备／共同恢复状态均强制锁定。普通自动锁定设置页不因此使开关失效。相应前台／敏感页回归保留。

新增双击开关浏览器用例最初在上一轮双击完成后500ms防穿透窗口内点击，受既有保护拦截；夹具推进501ms后再验证设置，不修改产品防穿透期限。其前20个续跑入口已通过，只补跑该入口及尚未运行部分。

全量续跑发现遮蔽演练旧断言仍要求热区贴视口、提示在顶部返回之下；按已确认的独立底部返回更新为演练内部12px内边距、提示与导航不重叠，并通过本机回归。Linux CI的移动编辑器用例因无平台验证器而进入密码布局；该用例明确固定通行密钥能力以检验名称编辑器，密码分支仍由数字页与Chamber专项覆盖。本机移动编辑器重验通过，完整CI须在最终候选重新通过。
