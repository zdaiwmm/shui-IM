## 修复与复查

| 问题 | 修复与证据 |
| --- | --- |
| P1 启动时图标节点层级错误 | 使用 Lucide 导出的节点数组；新页面完整渲染，最终控制台无 error |
| 输入 tips 造成溢出和聚焦时页面偏移 | 输入区 tips 朝上，预览容器 clip；根滚动为 0 |
| 浅色发送尾巴误用紫色 | 浅色尾巴明确绑定发送气泡色；重新截图并人工核对并排图 |
| Toast 覆盖失败重试入口 | 移至标题下方，非按钮区域不拦截点击，失败演示不再弹遮挡通知；重试复查成功 |
| 面板退出动画拦截返回点击 | closing 遮罩 pointer-events:none；快速 Esc + 返回可显示聊天输入 |
| 旧排版回调覆盖新发送位置 | 用排版版本号丢弃过期回调；发送后最新消息可见 |
| 连续视口事件丢失最新跟随 | 合并同帧原生视口事件，以跟随状态决定底部恢复；短视口最新位置与同宽历史偏移均复查通过 |

最终结论：P1 在已测浏览器与尺寸中的视觉对照、主要演示路径通过，无遗留 P0–P2 原型问题。此结论限定于本次原型，不代表正式应用、完整可访问性审计或安全验证。

材料检查：原型 3 个 JS/MJS 与静态绘制脚本均通过 `node --check`；JSON 可解析、相对文档链接存在、源码摘要一致。提交范围 12 个文本文件，约 139KB，无二进制、内嵌 Base64 素材、依赖或构建产物。静态绘制脚本只在运行时从外部本地 SVG 生成内存 Data URL，未保存素材负载。根 package.json／锁文件与正式代码无变动。

未验证：iPhone / iOS 27 / Safari 真机键盘、工具栏升降、中文输入法候选条；真实触摸长按与滑动回复；系统拍摄选择和附件上传（原型无上传）；真实消息、麦克风、通话与回执。正式产品自动测试、CI、合并、生产发布均不在本轮范围。
