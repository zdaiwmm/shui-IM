## 方案与边界

- 目标：将半透明液态玻璃改为浏览器可稳定实现、精炼且有品质的 IM 视觉与交互体系。
- 用户约束：UI 元素不要太大；浅色与深色都应可体验；重点为聊天、设置、弹窗、半屏面板和交互动效，不需制作全部页面。
- 用户明确免除业务流程图；该例外只作用于本次设计材料。
- 浏览器约束：底部工具栏和键盘压缩聊天可视区。标题栏须支持紧凑输入态，优先保留消息列表空间，不能假定浏览器拥有原生 App 的可用高度。
- 保持无账号、两名参与者及既有安全、设备和消息语义。参考成熟 IM 不等于新增联系人列表、账号体系或群聊。
- 原型使用独立入口、模拟数据与内存状态，不导入正式应用入口、Service Worker、真实聊天或恢复材料。
