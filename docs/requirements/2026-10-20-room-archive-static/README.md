## 用户已确认的方案

1. 无注册首页创建密室；空聊天页提供复制邀请链接，不展示手工加入口令。对方打开后加入，成功消费链接后地址归首页。进入聊天后再进行隐私引导。
2. 普通刷新不丢失本机访问。设置内列出本地密室，可切换、改本机名称和删除。删除不关闭对方会话、不删除已完成的服务器备份。
3. 同密室新链接接替已有连接时保留本机历史；不同密室链接新增独立条目。手机只接替具体旧手机，电脑只接替具体旧电脑，不按类别踢掉全部同类设备。
4. 遮蔽层、应用锁与自动锁定、备份及本机恢复依次引导。应用锁同时保护页面访问和本机解密钥，服务器备份独立。
5. 默认自动备份，不等待任何一方设置恢复口令或保存卡片。双方各自有独立恢复材料；长恢复口令只保护本人导出的恢复卡图片。
6. 一张恢复卡指向一个归档中的本人读取能力；卡片加口令即可恢复，无需对方在线或授权。首页无恢复入口，恢复在当前密室设置发起。
7. 文字、图片原文件及附件一起恢复；恢复结果归属执行恢复的当前密室，不进入所有密室共用的可见历史库。
8. 导入历史与当前聊天一起备份，但只有本人有权读取导入部分。迁移完整提交后，当前卡恢复全部本人可读记录，不依赖旧卡或源密室继续存在。
9. 不设置备份过期时间。容量不足明确失败，不静默删除旧备份。

## S2 精简准则与变更

- 首页创建到聊天仅一次切换。A02 是 A01 按钮状态，不是页面；即时完成不展示忙碌动画，慢操作约 300 ms 后显示，无最短强制停留。
- 复制成功 B01、失败 B02、重复邀请本人 B11 等用原 toast，按钮仍叫“复制聊天链接”。已存在密室 B10 直接进入。
- B04 / B08 / B09 在聊天壳内连接、等待或重试。壳出现不代表协议完成；发送入口待加密连接完成才启用。未验证链接不能展示可信历史，也不能提前消费或撤销旧设备。
- D03 新设计的中间页撤销；指南进入现有遮蔽演练，设置进入现有遮蔽配置。A03 / D02 使用现有三步卡，仅调整步骤次序与业务文案。
- E01 / E02 不展示；自动判断已有保护及可用能力，直接进入现有验证。系统验证取消不能被当成自动降级授权。
- F02 不存在独立页面；慢切换仅列表行忙碌，失败保持列表。F03 复用现有离线聊天。F12 管理页改回既有长按菜单。
- H02–H08、K02/K03/K06/K08/K09 回到同一个备份总览。I01–I14 在制作页切换内容或就近反馈。J01–J15 在恢复页处理读取、摘要、进度和错误。
- F06/F07 合成一次删除确认；J10 暂停直接更新任务，不弹二次确认。确有不可逆后果或分享范围变化的操作仍保留确认。
- 最新修订覆盖：操作错误统一 toast，原入口保留；任务进度、真实备份状态及连接系统卡仍由原页面承载。
