## 定位与实现

- 排队视频只有绝对定位的文字和时长。全局媒体样式最终将气泡 aspect-ratio 设为 auto，排队内容不占布局，外框高度塌陷。改用现有 media-upload-previews 占位与 media-load-capsule 状态结构，保留消息节点、固定比例、时长、进度及失败状态。
- 下载详情完成／失败结果复用本机视频遮蔽卡，显示大封面、时长、私有标记和可换行文件名；第一次点击只显露封面，再次点击查看视频，关闭仍按现有生命周期处理。
- 更新器原来只等 Service Worker 激活广播；Safari 后台挂起或注册失败可能错过事件。加入无缓存公开版本号文件、60 秒前台检查、visibilitychange／pageshow／focus／online 重查、注册失败重试及活动 worker 查询。旧 worker 的版本号不能覆盖已发现的新版本。服务器公开文件仅包含版本 ID。
- 更新说明原来要求同一标签页 sessionStorage 存在“点过更新”标记，普通刷新与系统恢复升级会被挡住。改为按持久的实际版本变更在解锁聊天后显示；新安装不弹，已见不重复；到可见帧后才记为已见，提前锁定不消费提示。
- 保留已参与会话的原筛选规则；仅大视频能力判断中，已入选的当前设备能力取运行中客户端值，远端设备仍取已宣布能力，不把离线旧端当成已升级。旧版文件解析器写死 128 个 2 MiB 分块／256 MiB 上限，无法仅从发送端让它正常收取更大的原件；保留真实门槛并明确原因。256 MiB 内视频沿用现有 v1／v2 文件格式，缺少 video-preview-v1 时不附加新版预览字段；不转码、不改原字节、不绕过接收验证。
- PC 多行回复发送已在 WebKit 逐帧复现：消息先向下偏移约 47px 再向上。原顺序在草稿收缩动画启动后隐藏回复栏，使动画测得的输入区高度失效；调整为先清除同一已发送回复，再测量收缩。回归覆盖真实 handleSendText 的短文本／多行、有无回复、输入焦点、横向尺寸、固定栏和节点身份。
- 追加审查修正：公开版本查询与 Worker 维护解耦，注册／更新 Promise 挂起不阻塞后续前台与定时查询；恢复下载按原任务 ID 绑定进度与阶段。通过固定 release:prepare 生成 2026.11.17.1，并加入本批更新说明。
