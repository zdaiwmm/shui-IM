## 当前复现与提案的证据边界

当前参数模式依据审计所得的主要时长与 cubic-bezier 复现，含发送 280ms、回复回位 260ms、页面 380ms、弹层 320ms、图片缩放 340ms、详情进入 620ms／退出 520ms、阅读翻页 260ms。它是缩减版独立运行时，不是加载生产应用，也不表示所有行为与线上逐帧一致。

提案以分场景的临界阻尼模型演示非线性加减速和无明显回弹的停靠；持久层保存当前位移与速度，以支持反向接续。这个模型是待评审设计，不代表生产必须统一改成弹簧。手势跟随不受慢放影响。速度条表示活跃运动幅度，不是可比的真机帧率或物理速度测量。

本轮无法播放用户提供的 Telegram 参考视频，未声称提取其曲线。正文、图片、表情、设备、邀请及状态全部为示例。文字阅读不是 PDF/EPUB 引擎。缩放为双击／按钮和单指拖动演示，不声称完成多指捏合专项。录音、通话和原生浏览器工具栏不属于十组原型，前序浏览器背景评估另行保留。
