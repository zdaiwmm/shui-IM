# 聊天进入与首条未读 V1

2026-11-03 用户在本聊天确认进入优先首条未读、无未读续读、翻历史保留位置，明确直接实施并免原型，随后要求合并和生产发布。规则和起始基线为 60882de7，任务分支 codex/chat-entry-first-unread。生产切换仍需用户确认精确主线提交。

原来重进恢复本机锚点，胶囊点击直达最新。现在已解锁时按照现有跨设备可读区间查询，跳过控制、本人、隐藏和已删除消息；延迟结果遵循本次滚动操作，普通圆形按钮继续回到底部。断网时使用已保存的本机可见进度；升级后尚无该进度且离线时沿用原位置。分隔沿用移动视觉规范的日期标签。

服务端权限、跨设备区间与计数由 unread-server 专项覆盖。WebKit 和 Chromium 的桌面与移动布局在 chat-scroll-stability 中验证进页定位、用户先滑动和点击胶囊。真机触控未验证。正式 CI 和合并记录以本需求 PR 为准。
