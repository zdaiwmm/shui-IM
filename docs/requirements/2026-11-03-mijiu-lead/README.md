# mijiu.cloud 访客基础像素

2026-11-03，站点所有者在本次会话确认信任自营 Lead 平台，覆盖访客应用全部页面，包括邀请和聊天。仅授权本地实现与验证。起始基线及规则版本为 `60882de7a9eb2c6572784b28c2f52ff0a44ff6b2`，分支为 `codex/mijiu-lead-base`。此变更不涉及可见界面。

加载入口为访客主模块。仅对精确的 HTTPS 来源启用，保留现有邀请 URL；管理入口和其他来源不加载。源码、线上首页和主脚本检查未发现已有 Lead、标签管理器或追踪同意入口。浏览器先建队列，再异步加载 SDK。页面浏览由 SDK 自动记录，原地切换界面且 URL 未变时不会新增 PageView。没有添加转化事件。

Lead 是受信任的页面代码，可以读取页面中已解密的内容。普通 PageView 会剥离查询参数和片段。安全策略仅允许该 SDK 和该连接的事件、批次及回执接口，拒绝会发送完整网址的测试状态接口。平台测试会话的状态查询与结束功能受此限制。基础 SDK 自带的 Engagement 仍按其默认逻辑运行。

本地 Chrome 使用指向本机应用的测试域名映射，在打开页面前拦截全部外部请求，使用当前 SDK 内容和模拟收集回执。一个文档加载一次。首访、改变 URL 的 pushState、replaceState、前进、后退及直接改变 hash 各记录一次。相同 URL 的 replaceState 和创建后进入聊天的原地切换均为零。成功打开本地生成的短邀请并进入聊天，一次操作观测到三条 PageView（包括应用处理片段时的 URL 变化）。上报中无邀请片段。带虚构邀请码的测试状态请求被 CSP 阻止。其他生产来源和管理员登录页加载零次。后台收数未验证。

本地构建及原有 1,276 项自动测试通过；新增的安全策略测试单独通过。仓库全量浏览器回归 92 组通过。Chrome 专项未观察到页面脚本异常；本地应用接口返回过 404，刻意构造的无效邀请接口返回 500，测试状态请求按预期产生 CSP 控制台提示。未执行生产部署或后台回读。

用户后续授权提交、合并并请求双环境发布，要求 ai.shui.click 不包含像素信息。两环境沿用同一应用镜像，连接值由东京环境单独提供。公共静态包不含 SDK 地址、连接 ID 或像素 key；默认关闭的主站和非目标域名不能从运行时入口取得配置。发布仍须对精确 main 提交单独确认。

环境隔离版复核：完整静态构建扫描未检出 SDK 地址、安装值及 Lead 队列。已配置和未配置服务均通过域名及安全策略专项，真实 SDK 在联网拦截的本地 Chrome 中复测通过。
