## 已确认方案与原型范围

同一业务逻辑，手机单栏、PC 常驻空间侧栏与当前内容双栏；消息独立滚动、内容区两侧对齐且单气泡限宽、输入框底部停靠、宽窄切换保留状态。沿用当前色彩、系统字体、气泡和有限玻璃材质。

本次静态原型涵盖：空间切换与独立草稿；模拟发送、中文输入合成保护、换行；消息菜单、回复、附件收藏；图片和 PDF 模拟查看；设置、设备、备份与恢复入口；恢复失败重试与关闭取消；待建立与待授权空间；窄窗口抽屉；明暗主题；整个工作区遮蔽；五组可视化业务流程。

有限入口：相机、文件选择、通话、真实密钥管理、云备份开关仅展示说明或模拟反馈，不实际执行。无服务端、WebAuthn、加密、真实文件读写、通知或真实设备验证；不新增拖放、常驻录音入口或可拖动栏宽。所有模拟状态仅存在页面内存，刷新重置。不要输入真实消息或恢复材料。
