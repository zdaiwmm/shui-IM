## V1 方案与取舍

- 创建时需要新密码保护的流程，改为固定六位 ASCII 数字，允许首位为 0；点击输入两遍，满六位自动推进，一致后完成设置。
- 新数字密码空间日常解锁显示六个圆点；满六位自动验证，无文本输入框、无系统键盘。错误轻摇并清空，保留现有失败等待与恢复入口。
- 版式按标准 iPhone 六位数字解锁页：居中锁图标／标题／六圆点，三列圆形数字键、2–9 的字母标注，0 在末行居中；解锁底部右侧为空时“取消”、有输入时“删除”。左侧保留应用需要的“忘记密码？”；设置左侧为取消，右侧按需删除。
- 字号、空间关系与圆键是当前 P1 密码页的局部例外，按用户明确的 iPhone 方向还原；系统字体、44px 以上触区、明暗、键盘可达、减少动态和隐私清理边界保留。演示工具在页面外，不混入拟实施产品 UI。
- 旧长密码继续原输入方式，已有通行密钥按原系统验证；不批量迁移旧密码，不改变新保护的能力分流条件。恢复卡和双方授权不被六位密码替代。敏感操作布局本轮未重新设计，正式实施须保持对新数字保护的验证兼容。
- 用户已确认六位密码的空间缩小取舍。仅有 1,000,000 种数字组合；网页无法提供 iPhone Secure Enclave 的硬件防猜机制，Argon2id／前端延迟不能消除已取得密文包装的离线猜测风险。
- 设置／验证忙碌时禁止重复提交；取消、隐藏、pagehide、导航替换和原目标失效须清理输入与确认草稿，拒绝迟到结果。
- 无待澄清的设计方向。未指定机型截图，当前还原标准 iPhone 数字页的结构和比例，不能声明与特定 iOS 27 系统页逐像素一致。
