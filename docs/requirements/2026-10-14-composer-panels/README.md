## 方案与版本

- V1：沿用现行 P1 不透明表面、系统字体、轻分隔和四套配色／明暗。表情保持一排添加、Emoji、已安装合集；Fluent 在前、Unicode 分类连续滚动。工具保留图片、拍摄、视频通话、实时语音、文件、收藏的四列顺序。
- V1.1：用户补充输入框。输入框 12px 圆角、16px 字体、44px 基础高度，内容增长到 88px 后内部滚动；发送按钮保持 44px 热区。Emoji 插入选区，Fluent／贴纸模拟发送后保留面板，草稿在面板切换中保留。
- V1.2：根据浏览器审阅，输入框填充从 `surface-raised 78%` 调整为 `composer-surface 76% + surface-raised 24%`，减少与输入栏底色的差异。上下留白从各 4px 增至各 8px，输入栏基准高度由 52px 调整至 60px。桌面锚定面板同步保持距输入栏 8px。
- V1.3：根据后续反馈移除输入框常态边线／内描边，仅用淡填充区分；鼠标、触屏点击不显示聚焦外框。仅 Tab 导航显示可定位的键盘焦点。高对比及系统强制颜色模式保留必要边界。
- V1.4：用户认为浅色两面板的白底不协调。表情与聊天工具统一采用 `surface 70% + composer-surface 30%` 的主题浅底，内容与入口共用同一画布；深色继续使用 `surface-raised`。此为V1.5确认表面，实施使用公共语义token。
- V1.5：表情添加入口改为简约的折角贴纸轮廓加中央小加号，输入栏加号不变。工具面板改平直四角，去掉装饰柄与其预留空间，顶部／底部改为 12px；桌面工具浮层同样使用平直四角。
- V1.5 动效：工具独立进退 240ms，普通首次段使用零起止速度的三次轨迹，反向继承当前位置与速度；表情及输入行交接使用现有 360ms／频率 25 的临界阻尼拟合。几何只提交最终布局，持续位移由唯一动效所有者用 transform 完成；离开面板立即 inert／aria-hidden，视觉退场后隐藏，不在开始关闭时直接消失。快速再次打开沿当前绘制位置与速度续接；重复目标不重播。半屏／全屏同样只对最终几何做位移衔接。减少动态和后台／pagehide 立即结束动效到目标状态，不等待装饰动画。
