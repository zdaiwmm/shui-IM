## 实施方案

六个入口为总览、密室管理、归档与备份、表情资源、运维诊断、安全与审计。表情库、显式采集、任务和内置动画说明整合在资源分栏中，采集完整验证后自动上架的契约保持。贴纸默认优先；GIF 兼容管理保留。

新版本人归档、旧版恢复备份、服务器灾备分别表达。新接口只投影必要元数据：编号、角色、写入端、对象数、字节数、来源存在及写入端授权状态。旧归档无可追溯时间时保持未知；只为新注册和实际新增对象记录时间，重复上传不刷新时间。对象数不是消息数，也不证明备份完整。

清理分为范围预览、完整编号及新因素验证、执行、回查。清理实时密室、关联旧版备份及在线附件，保留新版独立归档、独立快照和终端副本。零消息、无活跃写入端或来源密室消失都不成为独立归档回收依据。设备管理仅供诊断，不新增代授权、代恢复或归档删除能力。

灾备进程每 30 秒向独立状态卷发布白名单摘要，应用仅只读挂载该卷，通过 `ADMIN_BACKUP_STATUS_FILE` 读取最多 4 KiB。采样超过 120 秒、未来或无效时显示未知；备份新鲜度仍沿用原有效期门禁（缺省 36 小时）。该通道不挂载、枚举或下载快照，也不改变备份生成、校验、保留或 Mac 拉取周期。未接入时明确未知。通话配置、通知启用与实际送达/连通性分开。没有新增第三方脚本、统计、远程字体或外部运行依赖。
