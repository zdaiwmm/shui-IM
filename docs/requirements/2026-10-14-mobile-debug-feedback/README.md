草稿仅当前内存，完成仅派发原字段input/change，不代替业务确认或认证，不额外落盘；密码精确Unicode不trim/normalize。原页面仍保留原字段，隐私遮蔽不是认证。浮层不复制整个私密页面，不改变协议、密钥、设备或恢复权限。
