# R1 审阅与实施流程

用户已明确确认R1，当前进入正式修正与验证。确认对象包含维护规范 V1.4、审计差异和四批实施范围；不改变既有业务、安全与发布门禁。

```mermaid
flowchart TD
  A[读取维护规范与实际页面] --> B[移动设备模拟实页调试及源码核对差异]
  B --> C[Codex 中审阅 R1 目标]
  C --> D{用户确认版本并允许实施}
  D -->|需调整| C
  D -->|确认| E[基础与控件]
  E --> F[全页面与半屏]
  F --> G[聊天 媒体 与连续动效]
  G --> H[真实项目移动预览]
  H --> I[桌面尺寸 明暗 短视口回归]
  I --> J[真实键盘与系统区域补充验收]
  J --> K[同步规范 样例 差异与证据]
  K --> L[按授权提交 PR CI 集成]
  L --> M[本次不自动发布生产]
```

```mermaid
flowchart LR
  A[页面列表] --> B[进入完整页]

  K --> L[连续退出 恢复有效来源]
  G --> L
  B --> P[遮蔽或锁定]

  C --> P
```

```mermaid
flowchart LR
  A[媒体首次插入 锁定可信几何] --> B[准备]
  B --> C[上传中 真进度]
  C --> D[附件上传完成 消息提交中]
  D --> E[服务已保存 单勾]
  E --> F[对方设备接收 仍无已读事实]
  F --> G[真实已读回执 双勾]
  C --> H[上传失败32px胶囊]
  H -->|同ID重试| C
  H --> I[文字动作 移除未发送媒体]
  D --> J[消息提交失败 同提交重试]
  J --> D
  K[接收端 等待加载] --> L[下载 解密 生成模糊预览]
  L --> M[保持遮蔽 轻点显现]
  M --> N[查看]
  L --> O[真实错误原因与重试]
  O --> L
```

所有媒体状态复用同一几何和右下32px胶囊宿主；内容180ms、外壳240ms、必要尺寸补全280ms，途中从当前状态续接。上述关系表达已有业务事实，不新增协议；精确失败分期及不可用状态依实际错误来源实施，不能用视觉样例伪造回执。通话记录消息、永久不可用分类和动作Toast不在本批协议范围内。

每次后续项目决定形成后，在同一需求中更新规范参数、相关样例、差异编号和验收证据；待实施、已实现、待真机分别记录。Word/图解导出注明版本，旧快照不冒充最新维护源。
