# 聊天首屏延迟读取大视频
用户在本次会话反馈「刚进聊天，什么都没点就卡」，并于 2026-11-04 确认「同意，先修卡顿，再看下载器原型」。本项仅修加载时机，复用已有封面、占位、遮蔽和播放器，无页面改版。下载器 V2 单独评审。规则及基线 34e16c07，分支 codex/chat-entry-large-video-20261104。

旧线上版本 306f0b22 在移动 Chrome 模拟、180 条合成加密记录中，首屏出现没有封面但已缓存的 130 MiB 视频时自动解密 65 个分块，位于首屏之外时没有读原片。纯文字对照的初次绘制中位数为前版 107 ms、本版 109 ms。未在用户的真实设备复现。

验收覆盖首屏内外、已有原片内存缓存、持久化缓存、遮蔽和显式播放。只调整聊天缩略图调度，不修改附件格式、存储、网络、加密或隐私清理。关联 tests/video-flow.e2e.mjs，按附件 UI 变更进行本地 check、视频专项及云端回归。未获本次生产发布授权。

本地移动 Chrome 复测使用可解码的约 130 MiB 视频：首屏内外各两次，静置均为零原片分块；可见的两次点开后均完成原片读取并解出画面。video-flow 浏览器专项与本地 check（1303 项）通过。未在真机或生产环境执行。
