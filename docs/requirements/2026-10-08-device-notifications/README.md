## 方案与边界

- 入口：空间列表 → 设置 → 本机 → 通知管理。当前浏览器／主屏幕应用管理本机全部空间，不能修改对方或其他设备。
- 支持、主屏幕要求、系统阻止、服务暂不可用、网络暂未确认分别显示。用户明确开启时才请求系统通知权限；不提供测试或送达确认。
- 总开关控制本机通知，关闭保留各空间选择；默认已加入空间参与提醒。单空间关闭只删除对应 room/device 服务端订阅，不退订共享浏览器端点。新加入空间在已有总开关与系统授权下按本机偏好登记。
- 开启总开关对可管理空间完成签名订阅／退订及服务端确认后开放提醒。旧浏览器订阅兼容迁移，但各空间显示单独读取的服务端确认，不能仅根据浏览器订阅宣称成功。
- 同一已解锁通行密钥可短暂打开所属本机保险库以管理通知，不切换空间、不读聊天历史；其他凭据的空间在显式设置操作中按原验证要求处理。无法访问的目录空间显示受限，不能自动获得设备权限。
- 本机非敏感开关只保存布尔值和 room ID；不含名称、消息、身份令牌、密钥及恢复材料，不同步到云端或其他设备。总开关另存持久 worker gate，关闭后抑制已排队提醒，升级保留；浏览器端点随后退订。
- 跨标签页用 Web Locks 串行保存。网络与 worker 等待有上限；隐私锁定、离开页面及运行时结束后拒绝迟到开启结果。用户明确关闭后，持久 gate 与关闭意图一起保留，即使锁定中止了后续浏览器订阅清理，也不能在解锁后显示旧总开关。
- 通知只包含通用新消息提醒，点击后仍需解锁；通知不是已送达或已读事实，网络／专注模式等仍影响送达。
- 必需存储适配：旧表全局 `UNIQUE(endpoint)` 阻止一个浏览器为多个空间订阅。原子迁移为 `UNIQUE(room_id, endpoint)`，保留原行、设备主键与外键；过期端点仍清理全部相关空间。
- 排除：所有备份／恢复功能提案、设置覆盖扩展、附件校验流程、云端加密文案改版、消息或密码学协议、推送测试入口、第三方遥测、生产发布。
