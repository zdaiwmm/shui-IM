## 根因与实现

- WebKit 合成浏览器实测 `navigator.storage.getDirectory()` 抛出与截图相同的 `UnknownError`，连三字节合成文件都尚未写入；不能将其推断为用户手机内存不足。修复在临时存储不支持/不可用时，用最多 64 MiB 的密文 Blob 分片备用输出，超过上限明确失败；配额耗尽与取消不伪装为成功。可用 OPFS 仍流式写入，保留原归档格式、加密和校验边界。
- 旧长按与到期入口和新版删除实现并存。统一入口，删除非当前空间时保留当前会话与选中槽位，用独立目标会话验证；本地删除绑定目标槽位及快照，防止选中状态变化删错。
- 待加入空间删除与本人加密目录墓碑更新在同一 SQLite 事务提交，目录能力、活跃设备与版本冲突校验继续有效；对方已加入则整体拒绝。修正先删房间导致后续目录令牌失效的问题。已提交但响应丢失时，根据认证解密的目录墓碑完成重试。
- 在线解锁浏览器和已打开抽屉每约 3 秒刷新目录，离线保留最后确认状态并在重连后重试。接收端持久化删除标记，过滤本机残留目录；陈旧目录再次发布时墓碑优先。仅被认可目录、尚无空间设备身份的浏览器不能获得房间删除权限；引导在创建空间的原设备删除。
- 导出回归原来忽略下载按钮等待超时；现在要求真实下载事件、下载无错误，并认证读取下载文件的消息内容。
