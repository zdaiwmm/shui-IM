### 已确认的原型范围

1. 图片、视频、文件与表情并排对比，统一阶段切换、各自独立选择和播放。
2. 过程／失败24px；完成后的时间、回执与就绪提示20px；重试等实际可操作区域至少44px。
3. 新24/20与旧32/32可切换；发送、接收、失败重试、离线等待、暂停、移除、永久不可用与视频封面异常。
4. 浅色／深色、慢放、减少动态、热区查看与表情自动遮蔽开关。

### 设计取舍与现行产品差异

- 基于 `DESIGN.md`、`docs/design/mobile-visual-standard.md` 第11节与现行 `src/design-tokens.css`、`src/design-system.css`、`src/memes.css`、`src/lib/media-capsule.ts`。沿用字体、主题、壁纸、既有Lucide图标与现成Fluent表情。
- 用户授权制作24/20目标的原型；正式规范11.3仍为32px，尚未改写为已实现状态。
- 普通文件原型从准备起保留卡片；现行产品上传前仍用公共进度区，这是本次待审建议。
- 原型把接收处理状态按稳定的阶段展示，不复刻分块回调导致的文案来回切换；不改变真实流式安全处理。
- 消息服务保存、对方设备接收、已读、媒体显现、视频播放与文件阅读分别表达。模拟时间固定16:20，不能当作服务阶段时间。
- 媒体首触显现、后续查看／播放；白名单文件用静态模拟阅读页，不解析用户文件。表情默认不遮蔽，可独立开启自动遮蔽。
- 视频无封面时给明确的两步操作提示；这是待审表现，尚未改正式组件。
- 文字180ms、外壳240ms、比例180ms；尺寸一次提交后仅做变换与反向补偿，减少动态立即稳定，后台暂停演示。
