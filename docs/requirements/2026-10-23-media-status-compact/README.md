### 已确认的原型范围

1. 图片、视频、文件与表情并排对比，统一阶段切换、各自独立选择和播放。
2. 过程／失败24px；完成后的时间、回执与就绪提示20px；重试等实际可操作区域至少44px。
3. 新24/20与旧32/32可切换；发送、接收、失败重试、离线等待、暂停、移除、永久不可用与视频封面异常。
4. 浅色／深色、慢放、减少动态、热区查看与表情自动遮蔽开关。
