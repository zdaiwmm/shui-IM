# 附件紧凑状态流程 V1

状态与原型版本：V1，待设计确认。可查看、可点击的同语义流程位于原型「业务流程」页。
图中回执与连接都是模拟事件，不执行真实发送、加密或权限操作。

```mermaid
flowchart TD
  A[我选择图片、视频、文件或表情] --> B[本机准备：过程24px]
  B --> C{是否具备发送条件}
  C -->|等待连接| D[静态等待：无百分比、无发送勾]
  D -->|恢复连接| E[加密上传：过程24px]
  C -->|可以发送| E
  E -->|上传失败| F[上传失败与原位重试：24px，热区44px]
  F -->|同一附件续传| E
  E --> G[消息提交与等待确认：过程24px]
  G -->|消息提交失败| H[发送失败：原位重试]
  H -->|仅重试消息提交| G
  G -->|服务确认| I[服务已保存：完成20px，单勾]
  I --> J[对方设备已接收：仍为单勾]
  J --> K{是否收到有效已读回执}
  K -->|没有| J
  K -->|有| L[对方已读：完成20px，双勾]
  B -->|移除未发送附件| M[移除占位，不生成取消消息]
  D -->|已知接入失效| N[发送暂停，无旋转环]
```

```mermaid
flowchart TD
  A[收到附件消息：时间事实独立保留] --> B[等待加载：过程24px，静态环]
  B --> C[下载附件：过程24px，真实比例]
  C -->|下载失败| D[下载失败与原位重试：24px，热区44px]
  D -->|重建完整反馈结构| C
  C --> E[解密与完整性校验]
  E -->|可恢复处理失败| F[保持遮蔽并允许重试]
  F --> E
  E -->|完整验证后| G[本机生成预览或准备受限阅读]
  G --> H{附件类型}
  H -->|图片或有封面视频| I[安全遮蔽就绪：20px轻点显示]
  H -->|表情自动遮蔽开启| I
  H -->|表情自动遮蔽关闭| J[直接显示：透明20px时间行]
  H -->|白名单文件| K[打开模拟阅读页]
  H -->|视频封面不可用| L[20px预览不可用提示]
  I -->|首次点击| M[原位显现：20px时间行]
  M -->|再次点击| N[图片查看器或视频播放器]
  J -->|点击查看| N
  L -->|首次点击明确下一步| O[轻点播放提示]
  O -->|再次点击| N
  C -->|已确认永久不可用| P[内容不可用：20px，无重试]
  N -->|关闭或Escape| M
```

共同高优先级分支：锁定、隐私终止、运行期退出立即停止处理与预览，不等待过渡；
原型离开页面只暂停模拟与关闭媒体，不代表真实安全清理已经验证。

视觉过渡：文字180ms交叉淡化、外壳240ms变换、比例180ms；
过程与完成在同一宿主中从24px收为20px；减少动态时立即稳定到最终画面。
