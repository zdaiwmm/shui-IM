## 确认方案与边界

1. 顶部更新提示使用有按钮样式的「更新」。点击同步保存当前加密草稿并直接刷新，不再弹二次确认；保存失败留在原页面并可重试。
2. PC 日常空闲、后台和空白双击锁定仍立即移除私密画面、断开传输并停止媒体，只在当前页面内存保留最多30分钟续接材料。显式原入口进入时消费材料、重读精确保险库并复核成员；30分钟未进入、刷新／重开、硬生命周期、撤销及敏感操作仍需原认证。重复事件不续期，其他标签不继承材料；手机沿用硬锁。
3. PC 设置新增「在应用中打开」：可用时调用浏览器原生PWA安装；有当前安装证据时提供协议打开；否则显示对应浏览器引导。独立应用窗口显示已在应用中。Safari加入程序坞可能使用独立数据，须重新设备授权，不自动复制浏览器历史。没有原生客户端或后台服务承诺。
4. 默认自动锁定30秒；选项20、30、40、50秒，1、2、3、4、5分钟、永不。即选即保存，无保存按钮，失败恢复原选择。已有显式选择不迁移；永不只关闭普通空闲期限，敏感上限与硬锁保留。
5. 默认蓝、松绿、雾紫、暖杏四套整体配色，共用现有token和系统明暗，本机保存并同步同来源标签；危险等语义色保留。
6. 设置平铺，去掉本机／空间分类；设备、恢复等动作仍针对原目标空间，不因平铺改变权限或作用域。

设计依据为起始基线的 DESIGN／PRODUCT、`src/design-system.css`、`desktop.css`、`space-drawer.ts`；沿用原字体、材料、间距和图标。偏好页内容最大560px，原生单选整行命中至少44px，即时状态与错误就地反馈。无原型／流程图产物，依用户本次明确例外直接实施。
