## 行为与边界

1. 登录页只显示 6 位动态码；服务端不再校验或接收业务所需的管理员密码。错误、超时、过期、退出与刷新恢复沿用后台流程。
2. 清理实时密室仍需有效会话、精确来源、CSRF、完整目标编号与一个未使用的新动态码。新版独立归档、独立灾备及设备副本的保留规则保持。
3. 保留每个可信来源每分钟 8 次的入口预算、单次验证并发和持久化 TOTP 防重放。补充整个管理员配置共享的连续失败计数：5 次失败后冷却 15 分钟，跨 IP、登录／清理及服务重启共用；成功验证清零，冷却期间的请求不延长锁定。恶意请求仍可能造成管理员暂时无法登录。
4. 这是用户选择的单因素认证，不再宣称密码加动态码双因素。验证器被复制即可生成可用动态码；不提供绕过验证器或忘记验证器的在线入口。
5. 原生产 v1 配置原样兼容，不重写配置、替换 TOTP 或改变它拥有的持久化计数器。新初始化为仅含版本与独立 TOTP 种子的 v2 配置。配置不进入 Git、聊天数据卷或日志。
6. 本次不修改普通用户的应用锁、归档凭证密码、聊天协议、恢复权限或私有数据。
